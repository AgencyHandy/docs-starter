The AgencyHandy API lets you automate lead creation, client management, order updates, and more from any external system or script. Every request is authenticated with an API key that you generate from your workspace settings. This guide walks you through generating your key and making your first API call.

<Note>
  You must be a **SuperAdmin** or **Admin** on your AgencyHandy workspace to generate an API key.
</Note>

## Base URL

All API requests are made to:

```
https://api.agencyhandy.com/api/v1
```

Replace `{{URL}}` with this base URL in all example requests throughout the API documentation.

## Step 1: Generate an API key

<Steps>
  <Step title="Open Workspace Configuration">
    Navigate to your workspace settings at:

    ```
    {{workspaceUrl}}/workspace-config?tab=api-key
    ```

    This opens the **API Key** tab inside Workspace Configuration.
  </Step>

  <Step title="Generate and copy your API key">
    Click **Generate** (or **Regenerate** if a key already exists). Copy the API key and store it securely — treat it like a password. AgencyHandy will not display it again after you leave the page.
  </Step>
</Steps>

<Warning>
  Regenerating your API key immediately invalidates the previous key. Any existing integrations using the old key will stop working until you update them with the new key.
</Warning>

## Step 2: Make your first call

Send your API key in the `x-api-key` header. The key belongs to one workspace, so the API reads the workspace from the key and you do not need to send a Company ID. This call returns the key's workspace ID and the workspaces linked to it:

### Endpoint

```
GET {{URL}}/accounts/companies
```

### Headers

| Header | Value |
|---|---|
| `x-api-key` | Your API key |

### Example request

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/accounts/companies" \
  --header "x-api-key: <YOUR_API_KEY>"
```

### Example response

```json
{
  "message": "Companies accosiated with API token.",
  "companyId": "6525994184e9ddd79853450e",
  "companies": [
    {
      "_id": "6525994184e9ddd79853450e",
      "name": "onethread123",
      "logo": "",
      "extraSmallLogo": "",
      "largeLogo": ""
    }
  ]
}
```

`companyId` is the workspace your API key belongs to. `companies` also lists any parent or sub-workspaces linked to it; an API key only works for its own workspace, so create a separate key in each workspace you want to automate.

## Authentication summary

Every authenticated request needs only your API key:

```
x-api-key: <YOUR_API_KEY>
```

- **Base URL:** every path starts with `https://api.agencyhandy.com/api/v1`. Calling `https://api.agencyhandy.com/accounts/companies` without `/api/v1` returns `404 API not found`.
- **`companyid` header (optional):** older examples send `companyid: <YOUR_COMPANY_ID>`. You can keep sending it, but it must be the key's own workspace ID. A different ID is refused with `403 PermissionError`.
- **`Authorization: Bearer <YOUR_API_KEY>`** also works if your tool can only send a bearer token. Send the key in one header only, not both.
- **`401 Invalid API key (jwt malformed)`** means the value is not the full key: copy the whole key when you generate it (the API Key list only shows its last five characters). **`401 Invalid api token`** means the key was deleted.
- Each call runs with the permissions of the member who created the key.

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/members" \
  --header "x-api-key: <YOUR_API_KEY>"
```

With your API key in hand, you are ready to use the rest of the AgencyHandy API. Continue to one of the endpoint guides below.
