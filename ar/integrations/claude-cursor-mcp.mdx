يتيح لك اتصال MCP في AgencyHandy التحدث إلى **Claude** أو **Cursor** بلغة طبيعية وتشغيل العمل اليومي في مساحة عمل AgencyHandy — دون فتح كل شاشة بنفسك.

تبقى السيطرة لديك. يعمل Claude وCursor فقط بمفتاح API لمساحة العمل الذي تنشئه، ويطلبان التأكيد عندما يطابق الاسم أكثر من شخص.

## طريقتان للاتصال

| أين يعمل وكيلك | طريقة الاتصال | الإعداد |
|---|---|---|
| **على جهازك** — Claude Desktop أو Cursor | حزمة `agencyhandy-mcp` التي يشغّلها التطبيق | **إعداد MCP لـ Claude أو Cursor** أدناه — يتطلب Node.js 20+ |
| **في السحابة** — Cloudflare Workers أو Vercel أو n8n أو Claude/Cursor مستضاف | خادم MCP المستضاف لدينا على `https://mcp.agencyhandy.com/` | **ربط وكيل سحابي** أدناه — لا شيء لتثبيته |

كلتا الطريقتين تستخدمان مفتاح API نفسه لمساحة العمل وتمنحان الوكيل الأدوات نفسها.

<Note>
  تحتاج إلى دور يمكنه فتح **Workspace Config** وإدارة **API keys** (عادةً **SuperAdmin** أو **Admin**). وللإعداد المحلي تحتاج أيضاً إلى **Node.js 20+** على الجهاز الذي يعمل عليه Claude Desktop أو Cursor — أما الخادم المستضاف فلا يتطلب أي تثبيت.
</Note>

## المتطلبات

| المتطلب | التفاصيل |
|---|---|
| **مساحة عمل AgencyHandy** | الوصول إلى **Workspace Config** ← **API Key** |
| **مضيف MCP** | Claude Desktop أو Cursor على جهازك، أو أي وكيل يستطيع استدعاء خادم MCP عبر HTTP |
| **Node.js** *(للإعداد المحلي فقط)* | الإصدار **20** أو أحدث (تحقق بـ `node -v`) |
| **حزمة MCP** *(للإعداد المحلي فقط)* | `npx -y agencyhandy-mcp@1` (الوسم `1` يوفّر **1.7.2+**) |

حزمة MCP على npm هي `agencyhandy-mcp`. يشغّلها Claude وCursor عبر `npx -y agencyhandy-mcp@1`.

## إعداد Claude أو Cursor MCP

استخدم هذه الطريقة عندما يعمل Claude Desktop أو Cursor على جهازك. أما إذا كان وكيلك يعمل في السحابة، فانتقل إلى **ربط وكيل سحابي**.

<Steps>
  <Step title="افتح Workspace Config">
    في AgencyHandy، افتح **Workspace Config** (إعدادات الشركة)، ثم انتقل إلى تبويب **API Key**.
  </Step>

  <Step title="أنشئ مفتاح API لمساحة العمل">
    أنشئ مفتاح API جديدًا لمساحة العمل (أو استخدم مفتاحًا محفوظًا). انسخ المفتاح عند ظهوره — لن يتمكن AgencyHandy من إظهار المفتاح الكامل لاحقًا.
  </Step>

  <Step title="انسخ إعداد MCP">
    في تبويب **API Key** نفسه، استخدم لوحة إعداد Claude / Cursor MCP. انقر **Copy MCP config** ليضم JSON مفتاحك ورابط الواجهة الخلفية.
  </Step>

  <Step title="الصق في Cursor أو Claude Desktop">
    الصق الإعداد في:

    - **Cursor**: مشروع أو مستخدم `.mcp.json`
    - **Claude Desktop**: `claude_desktop_config.json`

    أبقِ الأمر `npx -y agencyhandy-mcp@1` ومفتاح API كما تم إنشاؤهما.
  </Step>

  <Step title="أعد التشغيل وجرّب مطالبة">
    أغلق **Cursor** أو **Claude Desktop** بالكامل ثم أعد فتحه. بعد ذلك اطلب شيئًا بسيطًا مثل موجز صباحي لمساحة العمل.
  </Step>
</Steps>

<Tip>
  إذا لم يعثر Claude أو Cursor على خادم MCP، تأكد من تثبيت **Node.js 20+** وإعادة تشغيل التطبيق بعد حفظ الإعداد.
</Tip>

## ربط وكيل سحابي (خادم مستضاف)

إذا كان وكيلك يعمل في مكان لا يمكنك تثبيت حزمة فيه — Cloudflare Workers أو دوال Vercel أو n8n أو Claude/Cursor مستضاف — فوجّهه إلى خادم MCP الذي نستضيفه لك:

```
https://mcp.agencyhandy.com/
```

لا شيء لتثبيته ولا خادم لتشغيله. وثّق كل طلب بمفتاح API نفسه لمساحة العمل بوصفه bearer token. تُقرأ مساحة العمل من المفتاح، لذا يتصل كل مستخدم بمفتاحه الخاص.

**Cursor وClaude Code وأي مضيف يرسل ترويسات مخصصة:**

```json
{
  "mcpServers": {
    "agency-handy": {
      "url": "https://mcp.agencyhandy.com/",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```

**Claude Desktop** لا يستطيع إرسال ترويسات مخصصة، لذا اربطه عبر `mcp-remote`:

```json
{
  "mcpServers": {
    "agency-handy": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://mcp.agencyhandy.com/",
        "--header", "Authorization:Bearer YOUR_API_KEY"
      ]
    }
  }
}
```

**Claude Code** من سطر الأوامر:

```bash
claude mcp add agency-handy --transport http https://mcp.agencyhandy.com/ \
  --header "Authorization: Bearer YOUR_API_KEY"
```

<Note>
  العنوان هو **المسار الجذر** — `https://mcp.agencyhandy.com/` وليس `/mcp`. للتأكد من أن الخادم يستجيب، افتح `https://mcp.agencyhandy.com/health`.
</Note>

<Tip>
  هل تبني تكاملك الخاص عبر واجهة HTTP بدلاً من ذلك؟ أرسل ترويسة **`User-Agent`** مع طلباتك. بعض بيئات التشغيل — ومنها `fetch()` في Cloudflare Workers — لا ترسلها افتراضياً، والطلبات التي تخلو منها تُرفض قبل وصولها إلى الواجهة.
</Tip>

## أمثلة على المطالبات

استخدم لغة طبيعية. فضّل الاسم الكامل أو البريد عند تعيين العمل لاختيار الشخص الصحيح.

| الهدف | مثال مطالبة |
|---|---|
| **موجز صباحي** | «أعطني موجزًا صباحيًا: التذاكر المفتوحة والفواتير غير المدفوعة والعروض بانتظار العملاء.» |
| **تعيين تذكرة** | «عيّن تذكرة إعادة تصميم الصفحة الرئيسية لـ Acme إلى Jordan Lee (jordan@agency.com).» |
| **إرسال فاتورة** | «أرسل الفاتورة INV-1042 إلى العميل بالبريد.» |
| **إنشاء عميل محتمل** | «أنشئ عميلًا محتملًا لـ Nora Patel في Bright Studio، البريد nora@brightstudio.com.» |
| **وضع علامة مدفوعة على فاتورة** | «ضع علامة paid على الفاتورة INV-1042.» |

## عندما يشترك شخصان في الاسم نفسه

إذا كان في الفريق شخصان باسم Sara، فسيسأل Claude أيهما تقصد. إنه **لا يخترع** المعرّفات ولا يخمن بصمت.

ضمّن دائمًا **اسمًا كاملًا** أو **بريدًا** في المطالبة عندما قد تتعارض الأسماء.

## ما يعمل الآن مقابل ما لم يتوفر بعد

| يعمل الآن | غير متاح عبر MCP بعد |
|---|---|
| موجزات وعمليات بحث في العروض والمشاريع والتذاكر والفواتير | الرد في **client chat** عبر MCP |
| تعيين التذاكر وأعمال الفريق الأخرى | — |
| إنشاء عملاء محتملين | — |
| إرسال الفواتير ووضع علامة مدفوعة | — |

يدعم MCP قراءة مساحة العمل والإجراءات (إنشاء، تعيين، إرسال، تحديث) بمفتاح API الخاص بك. ردود دردشة العميل غير معروضة عبر MCP بعد — استخدم AgencyHandy لتلك المحادثات.

## ذات صلة

- أنشئ المفاتيح وانسخ الإعداد داخل التطبيق من **Workspace Config** → **API Key**

<Note>
  Latest package on the `1` tag is **1.7.2+**. Claude can read **`ah://api-context`** (also inside **`ah://full-context`**) for API path gotchas: leads, projects/orders, tasks, comments, labels, clients, invoices, vouchers, and forms.
</Note>

- خادم مستضاف للوكلاء السحابيين: `https://mcp.agencyhandy.com/` (فحص الحالة على `/health`)
- الحزمة: [`agencyhandy-mcp`](https://www.npmjs.com/package/agencyhandy-mcp) على npm (`npx -y agencyhandy-mcp@1`)
