AgencyHandy API আপনাকে যেকোনো বাহ্যিক সিস্টেম বা স্ক্রিপ্ট থেকে লিড তৈরি, ক্লায়েন্ট ম্যানেজমেন্ট, অর্ডার আপডেট এবং আরও অনেক কিছু স্বয়ংক্রিয় করতে দেয়। প্রতিটি অনুরোধ একটি API কী দিয়ে প্রমাণীকৃত হয়, যা আপনি আপনার ওয়ার্কস্পেস সেটিংস থেকে তৈরি করেন। এই গাইড আপনাকে কী তৈরি করা এবং আপনার প্রথম API কল করার ধাপগুলো দেখাবে।

<Note>
  API কী তৈরি করতে আপনাকে আপনার AgencyHandy ওয়ার্কস্পেসে **SuperAdmin** বা **Admin** হতে হবে।
</Note>

## বেস URL

সমস্ত API অনুরোধ করা হয়:

```
https://api.agencyhandy.com/api/v1
```

API ডকুমেন্টেশন জুড়ে সমস্ত উদাহরণ অনুরোধে `{{URL}}`-কে এই বেস URL দিয়ে প্রতিস্থাপন করুন।

## ধাপ ১: একটি API কী তৈরি করুন

<Steps>
  <Step title="Workspace Configuration খুলুন">
    এই ঠিকানায় আপনার ওয়ার্কস্পেস সেটিংসে নেভিগেট করুন:

    ```
    {{workspaceUrl}}/workspace-config?tab=api-key
    ```

    এটি Workspace Configuration-এর ভেতরে **API Key** ট্যাব খোলে।
  </Step>

  <Step title="আপনার API কী তৈরি এবং কপি করুন">
    **Generate** ক্লিক করুন (বা যদি ইতিমধ্যে একটি কী থাকে তাহলে **Regenerate**)। API কীটি কপি করুন এবং নিরাপদে সংরক্ষণ করুন — এটি পাসওয়ার্ডের মতো আচরণ করুন। পেজ ছেড়ে যাওয়ার পরে AgencyHandy এটি আর প্রদর্শন করবে না।
  </Step>
</Steps>

<Warning>
  আপনার API কী পুনরায় তৈরি করলে পূর্ববর্তী কীটি অবিলম্বে অকার্যকর হয়ে যায়। পুরানো কী ব্যবহার করা যেকোনো বিদ্যমান ইন্টিগ্রেশন নতুন কী দিয়ে আপডেট না করা পর্যন্ত কাজ করা বন্ধ করে দেবে।
</Warning>

## ধাপ ২: আপনার প্রথম কল করুন

আপনার API কী `x-api-key` হেডারে পাঠান। কী একটি ওয়ার্কস্পেসের অন্তর্গত, তাই API কী থেকেই ওয়ার্কস্পেস পড়ে নেয় এবং আপনাকে কোম্পানি আইডি পাঠাতে হবে না। এই কলটি কী-এর ওয়ার্কস্পেস আইডি এবং এর সাথে যুক্ত ওয়ার্কস্পেসগুলো ফেরত দেয়:

### এন্ডপয়েন্ট

```
GET {{URL}}/accounts/companies
```

### হেডার

| হেডার | মান |
|---|---|
| `x-api-key` | আপনার API কী |

### উদাহরণ অনুরোধ

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/accounts/companies" \
  --header "x-api-key: <YOUR_API_KEY>"
```

### উদাহরণ প্রতিক্রিয়া

```json
{
  "message": "Companies accosiated with API token.",
  "companyId": "6525994184e9ddd79853450e",
  "companies": [
    {
      "_id": "6525994184e9ddd79853450e",
      "name": "onethread123",
      "logo": "",
      "extraSmallLogo": "",
      "largeLogo": ""
    }
  ]
}
```

`companyId` হলো সেই ওয়ার্কস্পেস যার অন্তর্গত আপনার API কী। `companies` এর সাথে যুক্ত প্যারেন্ট বা সাব-ওয়ার্কস্পেসগুলোও তালিকাভুক্ত করে; একটি API কী শুধু নিজের ওয়ার্কস্পেসের জন্যই কাজ করে, তাই আপনি যে ওয়ার্কস্পেস স্বয়ংক্রিয় করতে চান তার প্রতিটিতে আলাদা কী তৈরি করুন।

## প্রমাণীকরণ সারসংক্ষেপ

প্রতিটি প্রমাণীকৃত অনুরোধে শুধু আপনার API কী লাগে:

```
x-api-key: <YOUR_API_KEY>
```

- **বেস URL:** প্রতিটি পাথ `https://api.agencyhandy.com/api/v1` দিয়ে শুরু হয়। `/api/v1` ছাড়া `https://api.agencyhandy.com/accounts/companies` কল করলে `404 API not found` ফেরত আসে।
- **`companyid` হেডার (ঐচ্ছিক):** পুরনো উদাহরণগুলো `companyid: <YOUR_COMPANY_ID>` পাঠায়। আপনি এটি পাঠাতে থাকতে পারেন, তবে এটি অবশ্যই কী-এর নিজস্ব ওয়ার্কস্পেস আইডি হতে হবে। ভিন্ন আইডি `403 PermissionError` দিয়ে প্রত্যাখ্যাত হয়।
- আপনার টুল শুধু বেয়ারার টোকেন পাঠাতে পারলে **`Authorization: Bearer <YOUR_API_KEY>`** ও কাজ করে। কী শুধু একটি হেডারে পাঠান, দুটোতে নয়।
- **`401 Invalid API key (jwt malformed)`** মানে মানটি সম্পূর্ণ কী নয়: কী তৈরির সময় পুরো কী কপি করুন (API কী তালিকায় শুধু শেষ পাঁচটি অক্ষর দেখানো হয়)। **`401 Invalid api token`** মানে কী মুছে ফেলা হয়েছে।
- প্রতিটি কল সেই সদস্যের অনুমতি নিয়ে চলে যিনি কী তৈরি করেছেন।

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/members" \
  --header "x-api-key: <YOUR_API_KEY>"
```

আপনার API কী নিয়ে আপনি AgencyHandy API-এর বাকি অংশ ব্যবহার করতে প্রস্তুত। নিচের এন্ডপয়েন্ট গাইডগুলোর একটিতে এগিয়ে যান।
