API AgencyHandy vám umožňuje automatizovat vytváření leadů, správu klientů, aktualizace objednávek a další činnosti z libovolného externího systému nebo skriptu. Každý požadavek je ověřen klíčem API, který vygenerujete v nastavení svého pracovního prostoru. Tento průvodce vás provede vygenerováním klíče a provedením prvního volání API.

<Note>
  Chcete-li vygenerovat API klíč, musíte být **SuperAdmin** nebo **Admin** ve svém workspace AgencyHandy.
</Note>

## Základní URL

Všechny požadavky API jsou zasílány na:

```
https://api.agencyhandy.com/api/v1
```

Ve všech ukázkových požadavcích v dokumentaci API nahraďte `{{URL}}` touto základní URL.

## Krok 1: Vygenerujte API klíč

<Steps>
  <Step title="Otevřete Konfiguraci workspace">
    Přejděte do nastavení workspace na adrese:

    ```
    {{workspaceUrl}}/workspace-config?tab=api-key
    ```

    Otevře se záložka **API klíč** v Konfiguraci workspace.
  </Step>

  <Step title="Vygenerujte a zkopírujte svůj API klíč">
    Klikněte na **Generovat** (nebo **Znovu generovat**, pokud klíč již existuje). Zkopírujte API klíč a bezpečně jej uložte — zacházejte s ním jako s heslem. AgencyHandy jej po opuštění stránky znovu nezobrazí.
  </Step>
</Steps>

<Warning>
  Opětovné vygenerování API klíče okamžitě zneplatní předchozí klíč. Všechny stávající integrace používající starý klíč přestanou fungovat, dokud je neaktualizujete novým klíčem.
</Warning>

## Krok 2: Proveďte své první volání

Odešlete svůj klíč API v hlavičce `x-api-key`. Klíč patří jednomu pracovnímu prostoru, takže API zjistí pracovní prostor z klíče a nemusíte posílat ID společnosti. Toto volání vrátí ID pracovního prostoru klíče a pracovní prostory, které jsou s ním propojeny:

### Endpoint

```
GET {{URL}}/accounts/companies
```

### Hlavičky

| Hlavička | Hodnota |
|---|---|
| `x-api-key` | Váš API klíč |

### Ukázkový požadavek

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/accounts/companies" \
  --header "x-api-key: <YOUR_API_KEY>"
```

### Ukázková odpověď

```json
{
  "message": "Companies accosiated with API token.",
  "companyId": "6525994184e9ddd79853450e",
  "companies": [
    {
      "_id": "6525994184e9ddd79853450e",
      "name": "onethread123",
      "logo": "",
      "extraSmallLogo": "",
      "largeLogo": ""
    }
  ]
}
```

`companyId` je pracovní prostor, ke kterému váš klíč API patří. `companies` také uvádí všechny nadřazené nebo podřízené pracovní prostory, které jsou s ním propojeny; klíč API funguje jen pro svůj vlastní pracovní prostor, proto vytvořte samostatný klíč v každém pracovním prostoru, který chcete automatizovat.

## Souhrn ověřování

Každý ověřený požadavek potřebuje pouze váš klíč API:

```
x-api-key: <YOUR_API_KEY>
```

- **Základní URL:** každá cesta začíná `https://api.agencyhandy.com/api/v1`. Volání `https://api.agencyhandy.com/accounts/companies` bez `/api/v1` vrátí `404 API not found`.
- **Hlavička `companyid` (volitelná):** starší příklady posílají `companyid: <YOUR_COMPANY_ID>`. Můžete ji dál posílat, ale musí to být ID vlastního pracovního prostoru klíče. Jiné ID je odmítnuto s `403 PermissionError`.
- **`Authorization: Bearer <YOUR_API_KEY>`** funguje také, pokud váš nástroj umí odeslat pouze bearer token. Klíč posílejte pouze v jedné hlavičce, ne v obou.
- **`401 Invalid API key (jwt malformed)`** znamená, že hodnota není celý klíč: při generování zkopírujte celý klíč (seznam klíčů API zobrazuje jen posledních pět znaků). **`401 Invalid api token`** znamená, že klíč byl smazán.
- Každé volání se provádí s oprávněními člena, který klíč vytvořil.

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/members" \
  --header "x-api-key: <YOUR_API_KEY>"
```

S vaším klíčem API jste připraveni používat zbytek API AgencyHandy. Pokračujte jedním z následujících průvodců koncovými body.
