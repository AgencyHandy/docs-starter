AgencyHandys MCP-forbindelse lader dig tale med **Claude** eller **Cursor** på almindeligt sprog og udføre dagligt arbejde i dit AgencyHandy-arbejdsområde — uden at åbne hvert skærmbillede selv.

Du bevarer kontrollen. Claude og Cursor handler kun med den API-nøgle til arbejdsområdet, du genererer, og beder dig bekræfte, når et navn matcher mere end én person.

## To måder at forbinde på

| Hvor din agent kører | Sådan forbinder du | Opsætning |
|---|---|---|
| **På din computer** — Claude Desktop eller Cursor | Pakken `agencyhandy-mcp`, som appen starter | **Opsæt Claude eller Cursor MCP** nedenfor — kræver Node.js 20+ |
| **I skyen** — Cloudflare Workers, Vercel, n8n, en hostet Claude eller Cursor | Vores hostede MCP-server på `https://mcp.agencyhandy.com/` | **Forbind en cloud-agent** nedenfor — intet at installere |

Begge bruger den samme API-nøgle til arbejdsområdet og giver agenten de samme værktøjer.

<Note>
  Du skal have en rolle, der kan åbne **Workspace Config** og administrere **API keys** (typisk **SuperAdmin** eller **Admin**). Til den lokale opsætning skal du desuden have **Node.js 20+** på den maskine, hvor Claude Desktop eller Cursor kører — den hostede server kræver ingen installation overhovedet.
</Note>

## Krav

| Krav | Detaljer |
|---|---|
| **AgencyHandy-arbejdsområde** | Adgang til **Workspace Config** → **API Key** |
| **En MCP-vært** | Claude Desktop eller Cursor på din computer, eller enhver agent der kan kalde en MCP-server over HTTP |
| **Node.js** *(kun lokal opsætning)* | Version **20** eller nyere (tjek med `node -v`) |
| **MCP-pakke** *(kun lokal opsætning)* | `npx -y agencyhandy-mcp@1` (tagget `1` leverer **1.7.2+**) |

MCP-pakken på npm er `agencyhandy-mcp`. Claude og Cursor kører den med `npx -y agencyhandy-mcp@1`.

## Konfigurer Claude eller Cursor MCP

Brug denne vej, når Claude Desktop eller Cursor kører på din egen computer. Kører agenten i skyen, så spring videre til **Forbind en cloud-agent**.

<Steps>
  <Step title="Åbn Workspace Config">
    I AgencyHandy skal du åbne **Workspace Config** (virksomhedsindstillinger) og gå til fanen **API Key**.
  </Step>

  <Step title="Generér en API-nøgle til arbejdsområdet">
    Opret en ny API-nøgle til arbejdsområdet (eller brug en gemt). Kopiér nøglen, når den vises — AgencyHandy kan ikke vise den fulde nøgle igen senere.
  </Step>

  <Step title="Kopiér MCP-konfigurationen">
    På samme fane **API Key** skal du bruge Claude / Cursor MCP-panelet. Klik på **Copy MCP config**, så JSON indeholder din nøgle og backend-URL.
  </Step>

  <Step title="Indsæt i Cursor eller Claude Desktop">
    Indsæt konfigurationen i:

    - **Cursor**: projekt- eller bruger-`.mcp.json`
    - **Claude Desktop**: `claude_desktop_config.json`

    Behold kommandoen `npx -y agencyhandy-mcp@1` og din API-nøgle som genereret.
  </Step>

  <Step title="Genstart og prøv en prompt">
    Afslut helt og åbn **Cursor** eller **Claude Desktop** igen. Bed derefter om noget enkelt, f.eks. en morgenbriefing for arbejdsområdet.
  </Step>
</Steps>

<Tip>
  Hvis Claude eller Cursor ikke kan finde MCP-serveren, skal du bekræfte, at **Node.js 20+** er installeret, og at du genstartede appen efter at have gemt konfigurationen.
</Tip>

## Forbind en cloud-agent (hostet server)

Hvis din agent kører et sted, hvor du ikke kan installere en pakke — Cloudflare Workers, Vercel-funktioner, n8n eller en hostet Claude eller Cursor — så peg den mod den MCP-server, vi driver for dig:

```
https://mcp.agencyhandy.com/
```

Der er intet at installere og ingen server at holde kørende. Godkend hver forespørgsel med den samme API-nøgle til arbejdsområdet som bearer-token. Arbejdsområdet læses fra nøglen, så hver bruger forbinder med sin egen.

**Cursor, Claude Code og enhver vært, der sender egne headers:**

```json
{
  "mcpServers": {
    "agency-handy": {
      "url": "https://mcp.agencyhandy.com/",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```

**Claude Desktop** kan ikke sende egne headers — brug `mcp-remote` som bro:

```json
{
  "mcpServers": {
    "agency-handy": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://mcp.agencyhandy.com/",
        "--header", "Authorization:Bearer YOUR_API_KEY"
      ]
    }
  }
}
```

**Claude Code** fra kommandolinjen:

```bash
claude mcp add agency-handy --transport http https://mcp.agencyhandy.com/ \
  --header "Authorization: Bearer YOUR_API_KEY"
```

<Note>
  Adressen er **rodstien** — `https://mcp.agencyhandy.com/`, ikke `/mcp`. Åbn `https://mcp.agencyhandy.com/health` for at tjekke, at serveren svarer.
</Note>

<Tip>
  Bygger du i stedet din egen integration mod HTTP-API'et? Send en **`User-Agent`**-header med dine forespørgsler. Nogle runtimes — heriblandt `fetch()` i Cloudflare Workers — sender ingen som standard, og forespørgsler uden bliver afvist, før de når API'et.
</Tip>

## Eksempelprompts

Brug naturligt sprog. Foretræk fulde navne eller e-mails, når du tildeler arbejde, så den rigtige person vælges.

| Mål | Eksempelprompt |
|---|---|
| **Morgenbriefing** | “Giv mig en morgenbriefing: åbne tickets, ubetalte fakturaer og forslag, der venter på kunder.” |
| **Tildel en ticket** | “Tildel ticketen om Acme-hjemmesidens redesign til Jordan Lee (jordan@agency.com).” |
| **Send en faktura** | “Send faktura INV-1042 til kunden via e-mail.” |
| **Opret en lead** | “Opret en lead for Nora Patel hos Bright Studio, e-mail nora@brightstudio.com.” |
| **Markér en faktura som betalt** | “Markér faktura INV-1042 som paid.” |

## Når to personer har samme navn

Hvis to teammedlemmer hedder Sara, spørger Claude, hvem du mener. Den **opfinder ikke** ID’er og gætter ikke i stilhed.

Medtag altid et **fuldt navn** eller en **e-mail** i prompten, når navne kan kollidere.

## Hvad der virker nu vs endnu ikke

| Virker nu | Endnu ikke tilgængeligt via MCP |
|---|---|
| Briefinger og opslag på forslag, projekter, tickets og fakturaer | Svare i **client chat** via MCP |
| Tildel tickets og andet teamarbejde | — |
| Opret leads | — |
| Send fakturaer og markér som betalte | — |

MCP understøtter læsning af dit arbejdsområde og handlinger (opret, tildel, send, opdater) med din API-nøgle. Svar i klientchat er endnu ikke tilgængelige via MCP — brug AgencyHandy til de samtaler.

## Relateret

- Generér nøgler og kopiér konfigurationen i appen under **Workspace Config** → **API Key**
- Hostet server til cloud-agenter: `https://mcp.agencyhandy.com/` (helbredstjek på `/health`)
- Pakke: [`agencyhandy-mcp`](https://www.npmjs.com/package/agencyhandy-mcp) på npm (`npx -y agencyhandy-mcp@1`)

<Note>
  Latest package on the `1` tag is **1.7.2+**. Claude can read **`ah://api-context`** (also inside **`ah://full-context`**) for API path gotchas: leads, projects/orders, tasks, comments, labels, clients, invoices, vouchers, and forms.
</Note>
