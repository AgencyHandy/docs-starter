Die AgencyHandy-API ermöglicht es Ihnen, die Lead-Erstellung, Kundenverwaltung, Bestellaktualisierungen und mehr aus jedem externen System oder Skript heraus zu automatisieren. Jede Anfrage wird mit einem API-Schlüssel authentifiziert, den Sie aus Ihren Workspace-Einstellungen generieren. Dieser Leitfaden führt Sie durch die Generierung Ihres Schlüssels und die Durchführung Ihres ersten API-Aufrufs.

<Note>
  Sie müssen **SuperAdmin** oder **Admin** in Ihrem AgencyHandy-Workspace sein, um einen API-Schlüssel zu generieren.
</Note>

## Basis-URL

Alle API-Anfragen werden an folgende Adresse gestellt:

```
https://api.agencyhandy.com/api/v1
```

Ersetzen Sie `{{URL}}` durch diese Basis-URL in allen Beispielanfragen in der API-Dokumentation.

## Schritt 1: API-Schlüssel generieren

<Steps>
  <Step title="Workspace-Konfiguration öffnen">
    Navigieren Sie zu Ihren Workspace-Einstellungen unter:

    ```
    {{workspaceUrl}}/workspace-config?tab=api-key
    ```

    Dies öffnet den **API-Schlüssel**-Tab innerhalb der Workspace-Konfiguration.
  </Step>

  <Step title="API-Schlüssel generieren und kopieren">
    Klicken Sie auf **Generieren** (oder **Neu generieren**, falls bereits ein Schlüssel vorhanden ist). Kopieren Sie den API-Schlüssel und bewahren Sie ihn sicher auf — behandeln Sie ihn wie ein Passwort. AgencyHandy zeigt ihn nicht erneut an, nachdem Sie die Seite verlassen.
  </Step>
</Steps>

<Warning>
  Das Neu-Generieren Ihres API-Schlüssels macht den vorherigen Schlüssel sofort ungültig. Alle bestehenden Integrationen, die den alten Schlüssel verwenden, funktionieren nicht mehr, bis Sie sie mit dem neuen Schlüssel aktualisieren.
</Warning>

## Schritt 2: Ersten Aufruf ausführen

Senden Sie Ihren API-Schlüssel im `x-api-key`-Header. Der Schlüssel gehört zu einem Workspace, daher liest die API den Workspace aus dem Schlüssel und Sie müssen keine Unternehmens-ID senden. Dieser Aufruf gibt die Workspace-ID des Schlüssels und die damit verknüpften Workspaces zurück:

### Endpunkt

```
GET {{URL}}/accounts/companies
```

### Header

| Header | Wert |
|---|---|
| `x-api-key` | Ihr API-Schlüssel |

### Beispielanfrage

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/accounts/companies" \
  --header "x-api-key: <YOUR_API_KEY>"
```

### Beispielantwort

```json
{
  "message": "Companies accosiated with API token.",
  "companyId": "6525994184e9ddd79853450e",
  "companies": [
    {
      "_id": "6525994184e9ddd79853450e",
      "name": "onethread123",
      "logo": "",
      "extraSmallLogo": "",
      "largeLogo": ""
    }
  ]
}
```

`companyId` ist der Workspace, zu dem Ihr API-Schlüssel gehört. `companies` listet außerdem alle verknüpften übergeordneten Workspaces oder Unter-Workspaces auf; ein API-Schlüssel funktioniert nur für seinen eigenen Workspace. Erstellen Sie daher in jedem Workspace, den Sie automatisieren möchten, einen eigenen Schlüssel.

## Authentifizierungsübersicht

Jede authentifizierte Anfrage benötigt nur Ihren API-Schlüssel:

```
x-api-key: <YOUR_API_KEY>
```

- **Basis-URL:** Jeder Pfad beginnt mit `https://api.agencyhandy.com/api/v1`. Ein Aufruf von `https://api.agencyhandy.com/accounts/companies` ohne `/api/v1` liefert `404 API not found`.
- **`companyid`-Header (optional):** Ältere Beispiele senden `companyid: <YOUR_COMPANY_ID>`. Sie können ihn weiterhin senden, er muss aber die Workspace-ID des Schlüssels sein. Eine abweichende ID wird mit `403 PermissionError` abgelehnt.
- **`Authorization: Bearer <YOUR_API_KEY>`** funktioniert ebenfalls, wenn Ihr Tool nur ein Bearer-Token senden kann. Senden Sie den Schlüssel nur in einem Header, nicht in beiden.
- **`401 Invalid API key (jwt malformed)`** bedeutet, dass der Wert nicht der vollständige Schlüssel ist: Kopieren Sie den gesamten Schlüssel, wenn Sie ihn generieren (die Liste der API-Schlüssel zeigt nur die letzten fünf Zeichen). **`401 Invalid api token`** bedeutet, dass der Schlüssel gelöscht wurde.
- Jeder Aufruf wird mit den Berechtigungen des Mitglieds ausgeführt, das den Schlüssel erstellt hat.

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/members" \
  --header "x-api-key: <YOUR_API_KEY>"
```

Mit Ihrem API-Schlüssel sind Sie bereit, die restliche AgencyHandy-API zu verwenden. Fahren Sie mit einem der folgenden Endpunkt-Leitfäden fort.
