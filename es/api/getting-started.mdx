La API de AgencyHandy te permite automatizar la creación de leads, la gestión de clientes, las actualizaciones de pedidos y mucho más desde cualquier sistema externo o script. Cada solicitud se autentica con una clave de API que generas desde la configuración de tu espacio de trabajo. Esta guía te explica cómo generar tu clave y realizar tu primera llamada a la API.

<Note>
  Debe ser **SuperAdmin** o **Admin** en su espacio de trabajo de AgencyHandy para generar una clave de API.
</Note>

## URL base

Todas las solicitudes a la API se realizan a:

```
https://api.agencyhandy.com/api/v1
```

Reemplace `{{URL}}` por esta URL base en todas las solicitudes de ejemplo a lo largo de la documentación de la API.

## Paso 1: Generar una clave de API

<Steps>
  <Step title="Abrir Workspace Configuration">
    Vaya a la configuración de su espacio de trabajo en:

    ```
    {{workspaceUrl}}/workspace-config?tab=api-key
    ```

    Esto abre la pestaña **API Key** dentro de Workspace Configuration.
  </Step>

  <Step title="Generar y copiar su clave de API">
    Haga clic en **Generate** (o **Regenerate** si ya existe una clave). Copie la clave de API y guárdela de forma segura — trátela como una contraseña. AgencyHandy no la volverá a mostrar después de que abandone la página.
  </Step>
</Steps>

<Warning>
  Regenerar su clave de API invalida inmediatamente la clave anterior. Cualquier integración existente que use la clave antigua dejará de funcionar hasta que la actualice con la nueva clave.
</Warning>

## Paso 2: Realiza tu primera llamada

Envía tu clave de API en el encabezado `x-api-key`. La clave pertenece a un espacio de trabajo, así que la API obtiene el espacio de trabajo a partir de la clave y no necesitas enviar un ID de empresa. Esta llamada devuelve el ID del espacio de trabajo de la clave y los espacios de trabajo vinculados a él:

### Endpoint

```
GET {{URL}}/accounts/companies
```

### Encabezados

| Encabezado | Valor |
|---|---|
| `x-api-key` | Su clave de API |

### Solicitud de ejemplo

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/accounts/companies" \
  --header "x-api-key: <YOUR_API_KEY>"
```

### Respuesta de ejemplo

```json
{
  "message": "Companies accosiated with API token.",
  "companyId": "6525994184e9ddd79853450e",
  "companies": [
    {
      "_id": "6525994184e9ddd79853450e",
      "name": "onethread123",
      "logo": "",
      "extraSmallLogo": "",
      "largeLogo": ""
    }
  ]
}
```

`companyId` es el espacio de trabajo al que pertenece tu clave de API. `companies` también incluye los espacios de trabajo principales o secundarios vinculados; una clave de API solo funciona para su propio espacio de trabajo, así que crea una clave distinta en cada espacio de trabajo que quieras automatizar.

## Resumen de autenticación

Cada solicitud autenticada solo necesita tu clave de API:

```
x-api-key: <YOUR_API_KEY>
```

- **URL base:** todas las rutas empiezan por `https://api.agencyhandy.com/api/v1`. Llamar a `https://api.agencyhandy.com/accounts/companies` sin `/api/v1` devuelve `404 API not found`.
- **Encabezado `companyid` (opcional):** los ejemplos antiguos envían `companyid: <YOUR_COMPANY_ID>`. Puedes seguir enviándolo, pero debe ser el ID del propio espacio de trabajo de la clave. Un ID distinto se rechaza con `403 PermissionError`.
- **`Authorization: Bearer <YOUR_API_KEY>`** también funciona si tu herramienta solo puede enviar un token Bearer. Envía la clave en un solo encabezado, no en ambos.
- **`401 Invalid API key (jwt malformed)`** significa que el valor no es la clave completa: copia la clave entera cuando la generes (la lista de claves de API solo muestra sus últimos cinco caracteres). **`401 Invalid api token`** significa que la clave fue eliminada.
- Cada llamada se ejecuta con los permisos del miembro que creó la clave.

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/members" \
  --header "x-api-key: <YOUR_API_KEY>"
```

Con tu clave de API ya puedes usar el resto de la API de AgencyHandy. Continúa con una de las guías de endpoints que aparecen a continuación.
