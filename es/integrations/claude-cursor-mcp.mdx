La conexión MCP de AgencyHandy te permite hablar con **Claude** o **Cursor** en lenguaje natural y que ejecuten el trabajo diario en tu espacio de trabajo AgencyHandy — sin abrir cada pantalla tú mismo.

Tú mantienes el control. Claude y Cursor solo actúan con la clave API del workspace que generas, y te piden confirmación cuando un nombre coincide con más de una persona.

## Dos formas de conectarse

| Dónde se ejecuta tu agente | Cómo conectarlo | Configuración |
|---|---|---|
| **En tu ordenador** — Claude Desktop o Cursor | El paquete `agencyhandy-mcp`, iniciado por la aplicación | **Configurar Claude o Cursor MCP**, más abajo — requiere Node.js 20+ |
| **En la nube** — Cloudflare Workers, Vercel, n8n, un Claude o Cursor alojado | Nuestro servidor MCP alojado en `https://mcp.agencyhandy.com/` | **Conectar un agente en la nube**, más abajo — nada que instalar |

Ambas usan la misma clave API del espacio de trabajo y dan al agente las mismas herramientas.

<Note>
  Necesitas un rol que pueda abrir **Workspace Config** y gestionar **API keys** (normalmente **SuperAdmin** o **Admin**). Para la instalación local también necesitas **Node.js 20+** en el equipo donde se ejecuta Claude Desktop o Cursor — el servidor alojado no requiere ninguna instalación.
</Note>

## Requisitos

| Requisito | Detalles |
|---|---|
| **Espacio de trabajo de AgencyHandy** | Acceso a **Workspace Config** → **API Key** |
| **Un host MCP** | Claude Desktop o Cursor en tu ordenador, o cualquier agente que pueda llamar a un servidor MCP por HTTP |
| **Node.js** *(solo instalación local)* | Versión **20** o posterior (`node -v` para comprobarlo) |
| **Paquete MCP** *(solo instalación local)* | `npx -y agencyhandy-mcp@1` (incluye **1.7.2+** en la etiqueta `1`) |

El paquete MCP en npm es `agencyhandy-mcp`. Claude y Cursor lo ejecutan con `npx -y agencyhandy-mcp@1`.

## Configurar Claude o Cursor MCP

Usa esta opción cuando Claude Desktop o Cursor se ejecuta en tu propio ordenador. Si tu agente corre en la nube, salta a **Conectar un agente en la nube**.

<Steps>
  <Step title="Abrir Workspace Config">
    En AgencyHandy, abre **Workspace Config** (ajustes de la empresa) y ve a la pestaña **API Key**.
  </Step>

  <Step title="Generar una clave API del workspace">
    Crea una nueva clave API del workspace (o usa una que ya hayas guardado). Copia la clave cuando aparezca — AgencyHandy no podrá mostrar la clave completa después.
  </Step>

  <Step title="Copiar la config MCP">
    En la misma pestaña **API Key**, usa el panel de configuración Claude / Cursor MCP. Haz clic en **Copy MCP config** para que el JSON incluya tu clave y la URL del backend.
  </Step>

  <Step title="Pegar en Cursor o Claude Desktop">
    Pega la config en:

    - **Cursor**: proyecto o usuario `.mcp.json`
    - **Claude Desktop**: `claude_desktop_config.json`

    Mantén el comando `npx -y agencyhandy-mcp@1` y tu clave API tal como se generaron.
  </Step>

  <Step title="Reiniciar y probar un prompt">
    Cierra por completo y vuelve a abrir **Cursor** o **Claude Desktop**. Luego pide algo sencillo, como un briefing matutino de tu workspace.
  </Step>
</Steps>

<Tip>
  Si Claude o Cursor no encuentran el servidor MCP, confirma que **Node.js 20+** está instalado y que reiniciaste la app después de guardar la config.
</Tip>

## Conectar un agente en la nube (servidor alojado)

Si tu agente se ejecuta donde no puedes instalar un paquete — Cloudflare Workers, funciones de Vercel, n8n, o un Claude o Cursor alojado — apúntalo al servidor MCP que alojamos para ti:

```
https://mcp.agencyhandy.com/
```

No hay nada que instalar ni ningún servidor que mantener. Autentica cada petición con la misma clave API del espacio de trabajo como bearer token. El espacio de trabajo se lee de la clave, así que cada usuario se conecta con la suya.

**Cursor, Claude Code y cualquier host que envíe cabeceras personalizadas:**

```json
{
  "mcpServers": {
    "agency-handy": {
      "url": "https://mcp.agencyhandy.com/",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```

**Claude Desktop** no puede enviar cabeceras personalizadas, así que usa el puente `mcp-remote`:

```json
{
  "mcpServers": {
    "agency-handy": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://mcp.agencyhandy.com/",
        "--header", "Authorization:Bearer YOUR_API_KEY"
      ]
    }
  }
}
```

**Claude Code** desde la línea de comandos:

```bash
claude mcp add agency-handy --transport http https://mcp.agencyhandy.com/ \
  --header "Authorization: Bearer YOUR_API_KEY"
```

<Note>
  La dirección es la **raíz** — `https://mcp.agencyhandy.com/`, no `/mcp`. Para comprobar que el servidor responde, abre `https://mcp.agencyhandy.com/health`.
</Note>

<Tip>
  ¿Estás construyendo tu propia integración contra la API HTTP? Envía una cabecera **`User-Agent`** en tus peticiones. Algunos entornos — incluido el `fetch()` de Cloudflare Workers — no envían ninguna por defecto, y las peticiones sin ella se rechazan antes de llegar a la API.
</Tip>

## Ejemplos de prompts

Usa lenguaje natural. Prefiere nombres completos o correos al asignar trabajo para seleccionar a la persona correcta.

| Objetivo | Ejemplo de prompt |
|---|---|
| **Briefing matutino** | “Dame un briefing matutino: tickets abiertos, facturas sin pagar y propuestas esperando al cliente.” |
| **Asignar un ticket** | “Asigna el ticket del rediseño de la homepage de Acme a Jordan Lee (jordan@agency.com).” |
| **Enviar una factura** | “Envía la factura INV-1042 al cliente por correo.” |
| **Crear un lead** | “Crea un lead para Nora Patel en Bright Studio, email nora@brightstudio.com.” |
| **Marcar una factura como pagada** | “Marca la factura INV-1042 como paid.” |

## Cuando dos personas comparten el mismo nombre

Si dos compañeros se llaman Sara, Claude preguntará a cuál te refieres. **No inventa** IDs ni adivina en silencio.

Incluye siempre un **nombre completo** o un **email** en el prompt cuando los nombres puedan chocar.

## Qué funciona ahora vs todavía no

| Funciona ahora | Aún no disponible desde MCP |
|---|---|
| Briefings y consultas de propuestas, proyectos, tickets y facturas | Responder en el **client chat** desde MCP |
| Asignar tickets y otro trabajo del equipo | — |
| Crear leads | — |
| Enviar facturas y marcarlas como pagadas | — |

MCP permite leer tu workspace y realizar acciones (crear, asignar, enviar, actualizar) con tu clave API. Las respuestas del chat de cliente aún no están expuestas por MCP — usa AgencyHandy para esas conversaciones.

- Genera claves y copia la config en la app en **Workspace Config** → **API Key**

</Note>
