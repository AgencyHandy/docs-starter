API AgencyHandy به شما امکان می‌دهد ایجاد سرنخ، مدیریت مشتریان، به‌روزرسانی سفارش‌ها و موارد دیگر را از هر سیستم یا اسکریپت خارجی خودکار کنید. هر درخواست با یک کلید API که از تنظیمات فضای کاری خود می‌سازید احراز هویت می‌شود. این راهنما شما را در ساخت کلید و انجام اولین فراخوانی API همراهی می‌کند.

<Note>
  برای تولید API key باید **SuperAdmin** یا **Admin** در فضای کاری AgencyHandy خود باشید.
</Note>

## آدرس پایه

تمام درخواست‌های API به آدرس زیر ارسال می‌شوند:

```
https://api.agencyhandy.com/api/v1
```

در تمام درخواست‌های نمونه در مستندات API، `{{URL}}` را با این آدرس پایه جایگزین کنید.

## مرحله ۱: تولید API key

<Steps>
  <Step title="باز کردن پیکربندی فضای کاری">
    به تنظیمات فضای کاری خود در آدرس زیر بروید:

    ```
    {{workspaceUrl}}/workspace-config?tab=api-key
    ```

    این صفحه تب **API Key** را داخل پیکربندی فضای کاری باز می‌کند.
  </Step>

  <Step title="تولید و کپی API key">
    روی **Generate** (یا **Regenerate** اگر کلید قبلاً وجود دارد) کلیک کنید. API key را کپی کرده و آن را به‌طور امن ذخیره کنید — مانند یک رمز عبور با آن رفتار کنید. AgencyHandy پس از ترک صفحه، آن را دوباره نمایش نخواهد داد.
  </Step>
</Steps>

<Warning>
  تولید مجدد API key، کلید قبلی را فوری غیرفعال می‌کند. هر یکپارچه‌سازی موجود که از کلید قدیمی استفاده می‌کند تا زمانی که آن را با کلید جدید به‌روز نکنید از کار می‌افتد.
</Warning>

## مرحله ۲: اولین فراخوانی خود را انجام دهید

کلید API خود را در سرآیند `x-api-key` ارسال کنید. کلید متعلق به یک فضای کاری است، بنابراین API فضای کاری را از روی کلید می‌خواند و لازم نیست شناسه شرکت را ارسال کنید. این فراخوانی شناسه فضای کاری کلید و فضاهای کاری متصل به آن را برمی‌گرداند:

### Endpoint

```
GET {{URL}}/accounts/companies
```

### هدرها

| هدر | مقدار |
|---|---|
| `x-api-key` | API key شما |

### درخواست نمونه

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/accounts/companies" \
  --header "x-api-key: <YOUR_API_KEY>"
```

### پاسخ نمونه

```json
{
  "message": "Companies accosiated with API token.",
  "companyId": "6525994184e9ddd79853450e",
  "companies": [
    {
      "_id": "6525994184e9ddd79853450e",
      "name": "onethread123",
      "logo": "",
      "extraSmallLogo": "",
      "largeLogo": ""
    }
  ]
}
```

`companyId` فضای کاری‌ای است که کلید API شما به آن تعلق دارد. `companies` همچنین فضاهای کاری والد یا زیرمجموعه متصل به آن را فهرست می‌کند؛ کلید API فقط برای فضای کاری خودش کار می‌کند، پس در هر فضای کاری که می‌خواهید خودکار کنید یک کلید جداگانه بسازید.

## خلاصه احراز هویت

هر درخواست احراز هویت‌شده فقط به کلید API شما نیاز دارد:

```
x-api-key: <YOUR_API_KEY>
```

- **نشانی URL پایه:** هر مسیر با `https://api.agencyhandy.com/api/v1` شروع می‌شود. فراخوانی `https://api.agencyhandy.com/accounts/companies` بدون `/api/v1` خطای `404 API not found` برمی‌گرداند.
- **سرآیند `companyid` (اختیاری):** مثال‌های قدیمی‌تر `companyid: <YOUR_COMPANY_ID>` را ارسال می‌کنند. می‌توانید همچنان آن را ارسال کنید، اما باید شناسه فضای کاری خود کلید باشد. شناسه متفاوت با `403 PermissionError` رد می‌شود.
- اگر ابزار شما فقط می‌تواند توکن bearer ارسال کند، **`Authorization: Bearer <YOUR_API_KEY>`** نیز کار می‌کند. کلید را فقط در یک سرآیند ارسال کنید، نه در هر دو.
- **`401 Invalid API key (jwt malformed)`** یعنی مقدار، کلید کامل نیست: هنگام ساخت کلید، آن را به‌طور کامل کپی کنید (فهرست کلیدهای API فقط پنج نویسه آخر را نشان می‌دهد). **`401 Invalid api token`** یعنی کلید حذف شده است.
- هر فراخوانی با مجوزهای عضوی که کلید را ساخته اجرا می‌شود.

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/members" \
  --header "x-api-key: <YOUR_API_KEY>"
```

با کلید API خود آماده‌اید از بقیه API AgencyHandy استفاده کنید. به یکی از راهنماهای نقطه پایانی زیر ادامه دهید.
