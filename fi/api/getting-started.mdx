AgencyHandyn API:n avulla voit automatisoida liidien luonnin, asiakashallinnan, tilauspäivitykset ja paljon muuta mistä tahansa ulkoisesta järjestelmästä tai skriptistä. Jokainen pyyntö todennetaan API-avaimella, jonka luot työtilasi asetuksissa. Tämä opas neuvoo avaimen luomisessa ja ensimmäisen API-kutsun tekemisessä.

<Note>
  Sinun on oltava AgencyHandy-työtilasi **SuperAdmin** tai **Admin** luodaksesi API-avaimen.
</Note>

## Perus-URL

Kaikki API-pyynnöt tehdään osoitteeseen:

```
https://api.agencyhandy.com/api/v1
```

Korvaa `{{URL}}` tällä perus-URL:lla kaikissa API-dokumentaation esimerkkipyynnöissä.

## Vaihe 1: Luo API-avain

<Steps>
  <Step title="Avaa työtilan määritykset">
    Siirry työtilasi asetuksiin osoitteessa:

    ```
    {{workspaceUrl}}/workspace-config?tab=api-key
    ```

    Tämä avaa **API Key** -välilehden työtilan määrityksessä.
  </Step>

  <Step title="Luo ja kopioi API-avaimesi">
    Napsauta **Generate** (tai **Regenerate**, jos avain on jo olemassa). Kopioi API-avain ja säilytä se turvallisesti — käsittele sitä kuin salasanaa. AgencyHandy ei näytä sitä uudelleen sen jälkeen, kun poistut sivulta.
  </Step>
</Steps>

<Warning>
  API-avaimen uudelleenluominen mitätöi edellisen avaimen välittömästi. Kaikki vanhan avaimen käyttävät integraatiot lakkaavat toimimasta, kunnes päivität ne uudella avaimella.
</Warning>

## Vaihe 2: Tee ensimmäinen kutsusi

Lähetä API-avaimesi `x-api-key`-otsakkeessa. Avain kuuluu yhdelle työtilalle, joten API lukee työtilan avaimesta eikä sinun tarvitse lähettää yritystunnusta. Tämä kutsu palauttaa avaimen työtilan tunnuksen ja siihen linkitetyt työtilat:

### Päätepiste

```
GET {{URL}}/accounts/companies
```

### Otsikot

| Otsikko | Arvo |
|---|---|
| `x-api-key` | API-avaimesi |

### Esimerkkipyyntö

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/accounts/companies" \
  --header "x-api-key: <YOUR_API_KEY>"
```

### Esimerkkivastaus

```json
{
  "message": "Companies accosiated with API token.",
  "companyId": "6525994184e9ddd79853450e",
  "companies": [
    {
      "_id": "6525994184e9ddd79853450e",
      "name": "onethread123",
      "logo": "",
      "extraSmallLogo": "",
      "largeLogo": ""
    }
  ]
}
```

`companyId` on työtila, johon API-avaimesi kuuluu. `companies` listaa myös siihen linkitetyt ylä- tai alatyötilat; API-avain toimii vain omassa työtilassaan, joten luo erillinen avain jokaiseen työtilaan, jonka haluat automatisoida.

## Todentamisen yhteenveto

Jokainen todennettu pyyntö tarvitsee vain API-avaimesi:

```
x-api-key: <YOUR_API_KEY>
```

- **Perus-URL:** jokainen polku alkaa osoitteella `https://api.agencyhandy.com/api/v1`. Kutsu osoitteeseen `https://api.agencyhandy.com/accounts/companies` ilman `/api/v1` palauttaa `404 API not found`.
- **`companyid`-otsake (valinnainen):** vanhemmat esimerkit lähettävät `companyid: <YOUR_COMPANY_ID>`. Voit jatkaa sen lähettämistä, mutta sen on oltava avaimen oman työtilan tunnus. Eri tunnus hylätään virheellä `403 PermissionError`.
- **`Authorization: Bearer <YOUR_API_KEY>`** toimii myös, jos työkalusi voi lähettää vain bearer-tunnuksen. Lähetä avain vain yhdessä otsakkeessa, älä molemmissa.
- **`401 Invalid API key (jwt malformed)`** tarkoittaa, että arvo ei ole koko avain: kopioi koko avain, kun luot sen (API-avainluettelo näyttää vain sen viisi viimeistä merkkiä). **`401 Invalid api token`** tarkoittaa, että avain on poistettu.
- Jokainen kutsu suoritetaan avaimen luoneen jäsenen oikeuksilla.

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/members" \
  --header "x-api-key: <YOUR_API_KEY>"
```

API-avaimellasi voit käyttää muuta AgencyHandyn API:a. Jatka johonkin alla olevista päätepisteoppaista.
