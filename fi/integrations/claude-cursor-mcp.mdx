AgencyHandyn MCP-yhteys antaa puhua **Claudelle** tai **Cursorille** arkikielellä ja suorittaa päivittäistä työtä AgencyHandy-työtilassa — avaamatta jokaista näyttöä itse.

Sinä säilytät hallinnan. Claude ja Cursor toimivat vain generoimallasi työtilan API-avaimella ja pyytävät vahvistusta, kun nimi vastaa useampaa henkilöä.

## Kaksi tapaa yhdistää

| Missä agenttisi toimii | Miten yhdistät | Käyttöönotto |
|---|---|---|
| **Omalla koneellasi** — Claude Desktop tai Cursor | Sovelluksen käynnistämä `agencyhandy-mcp`-paketti | **Claude- tai Cursor-MCP:n käyttöönotto** alla — vaatii Node.js 20+ |
| **Pilvessä** — Cloudflare Workers, Vercel, n8n, isännöity Claude tai Cursor | Isännöity MCP-palvelimemme osoitteessa `https://mcp.agencyhandy.com/` | **Pilviagentin yhdistäminen** alla — ei asennettavaa |

Molemmat käyttävät samaa työtilan API-avainta ja antavat agentille samat työkalut.

<Note>
  Tarvitset roolin, joka voi avata **Workspace Config** -näkymän ja hallita **API keys** -avaimia (yleensä **SuperAdmin** tai **Admin**). Paikallista käyttöönottoa varten tarvitset lisäksi **Node.js 20+** siinä koneessa, jossa Claude Desktop tai Cursor toimii — isännöity palvelin ei vaadi asennusta lainkaan.
</Note>

## Vaatimukset

| Vaatimus | Tiedot |
|---|---|
| **AgencyHandy-työtila** | Pääsy kohtaan **Workspace Config** → **API Key** |
| **MCP-isäntä** | Claude Desktop tai Cursor koneellasi, tai mikä tahansa agentti, joka osaa kutsua MCP-palvelinta HTTP:n yli |
| **Node.js** *(vain paikallinen käyttöönotto)* | Versio **20** tai uudempi (tarkista `node -v`) |
| **MCP-paketti** *(vain paikallinen käyttöönotto)* | `npx -y agencyhandy-mcp@1` (tunniste `1` toimittaa **1.7.2+**) |

npm:n MCP-paketti on `agencyhandy-mcp`. Claude ja Cursor suorittavat sen komennolla `npx -y agencyhandy-mcp@1`.

## Claude- tai Cursor-MCP:n määritys

Käytä tätä, kun Claude Desktop tai Cursor toimii omalla koneellasi. Jos agenttisi toimii pilvessä, siirry kohtaan **Pilviagentin yhdistäminen**.

<Steps>
  <Step title="Avaa Workspace Config">
    Avaa AgencyHandyssa **Workspace Config** (yritysasetukset) ja siirry **API Key** -välilehdelle.
  </Step>

  <Step title="Luo työtilan API-avain">
    Luo uusi työtilan API-avain (tai käytä tallennettua). Kopioi avain, kun se näkyy — AgencyHandy ei voi näyttää täyttä avainta myöhemmin uudelleen.
  </Step>

  <Step title="Kopioi MCP-määritys">
    Samalla **API Key** -välilehdellä käytä Claude / Cursor MCP -paneelia. Napsauta **Copy MCP config**, jotta JSON sisältää avaimesi ja backend-URL:n.
  </Step>

  <Step title="Liitä Cursoriin tai Claude Desktopiin">
    Liitä määritys:

    - **Cursor**: projektin tai käyttäjän `.mcp.json`
    - **Claude Desktop**: `claude_desktop_config.json`

    Pidä komento `npx -y agencyhandy-mcp@1` ja API-avain sellaisina kuin ne generoitiin.
  </Step>

  <Step title="Käynnistä uudelleen ja kokeile kehotetta">
    Sulje **Cursor** tai **Claude Desktop** kokonaan ja avaa uudelleen. Pyydä sitten jotain yksinkertaista, esimerkiksi työtilan aamubriffiä.
  </Step>
</Steps>

<Tip>
  Jos Claude tai Cursor ei löydä MCP-palvelinta, varmista **Node.js 20+** ja käynnistä sovellus uudelleen määrityksen tallennuksen jälkeen.
</Tip>

## Pilviagentin yhdistäminen (isännöity palvelin)

Jos agenttisi toimii paikassa, johon et voi asentaa pakettia — Cloudflare Workers, Vercelin funktiot, n8n tai isännöity Claude tai Cursor — osoita se MCP-palvelimeen, jota ylläpidämme puolestasi:

```
https://mcp.agencyhandy.com/
```

Mitään ei tarvitse asentaa eikä palvelinta ylläpitää. Todenna jokainen pyyntö samalla työtilan API-avaimella bearer-tokenina. Työtila luetaan avaimesta, joten jokainen käyttäjä yhdistää omallaan.

**Cursor, Claude Code ja kaikki isännät, jotka lähettävät omia otsakkeita:**

```json
{
  "mcpServers": {
    "agency-handy": {
      "url": "https://mcp.agencyhandy.com/",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```

**Claude Desktop** ei osaa lähettää omia otsakkeita — käytä siltana `mcp-remote`-työkalua:

```json
{
  "mcpServers": {
    "agency-handy": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://mcp.agencyhandy.com/",
        "--header", "Authorization:Bearer YOUR_API_KEY"
      ]
    }
  }
}
```

**Claude Code** komentoriviltä:

```bash
claude mcp add agency-handy --transport http https://mcp.agencyhandy.com/ \
  --header "Authorization: Bearer YOUR_API_KEY"
```

<Note>
  Osoite on **juuripolku** — `https://mcp.agencyhandy.com/`, ei `/mcp`. Tarkista palvelimen tavoitettavuus avaamalla `https://mcp.agencyhandy.com/health`.
</Note>

<Tip>
  Rakennatko sen sijaan omaa integraatiota HTTP-rajapintaan? Lähetä pyyntöjesi mukana **`User-Agent`**-otsake. Jotkin ajoympäristöt — muun muassa Cloudflare Workersin `fetch()` — eivät lähetä sitä oletuksena, ja ilman otsaketta pyynnöt hylätään ennen kuin ne saapuvat rajapintaan.
</Tip>

## Esimerkkikehotteet

Käytä luonnollista kieltä. Suosi täyttä nimeä tai sähköpostia työtä määrätessäsi, jotta oikea henkilö valitaan.

| Tavoite | Esimerkkikehote |
|---|---|
| **Aamubrief** | “Anna aamubrief: avoimet tiketit, maksamattomat laskut ja asiakasta odottavat ehdotukset.” |
| **Määrää tiketti** | “Määrää Acme-etusivun uudistuksen tiketti Jordan Leelle (jordan@agency.com).” |
| **Lähetä lasku** | “Lähetä lasku INV-1042 asiakkaalle sähköpostilla.” |
| **Luo liidi** | “Luo liidi Nora Patelille Bright Studiosta, sähköposti nora@brightstudio.com.” |
| **Merkitse lasku maksetuksi** | “Merkitse lasku INV-1042 tilaan paid.” |

## Kun kahdella henkilöllä on sama nimi

Jos tiimissä on kaksi Saraa, Claude kysyy kumpaa tarkoitat. Se **ei keksi** ID:itä eikä arvaa hiljaa.

Sisällytä kehotteeseen aina **koko nimi** tai **sähköposti**, kun nimet voivat törmätä.

## Mikä toimii nyt vs ei vielä

| Toimii nyt | Ei vielä saatavilla MCP:stä |
|---|---|
| Briefit ja haut ehdotuksille, projekteille, tiketeille ja laskuille | Vastaus **client chat**issa MCP:stä |
| Tikettien ja muun tiimityön määrääminen | — |
| Liidien luonti | — |
| Laskujen lähetys ja maksetuksi merkintä | — |

MCP tukee työtilan lukemista ja toimintoja (luo, määrää, lähetä, päivitä) API-avaimellasi. Asiakaschat-vastaukset eivät ole vielä MCP:n kautta — käytä AgencyHandya näihin keskusteluihin.

## Aiheeseen liittyvää

- Luo avaimia ja kopioi määritys sovelluksessa: **Workspace Config** → **API Key**
- Isännöity palvelin pilviagenteille: `https://mcp.agencyhandy.com/` (tilatarkistus osoitteessa `/health`)
- Paketti: [`agencyhandy-mcp`](https://www.npmjs.com/package/agencyhandy-mcp) npm:ssä (`npx -y agencyhandy-mcp@1`)

<Note>
  Latest package on the `1` tag is **1.7.2+**. Claude can read **`ah://api-context`** (also inside **`ah://full-context`**) for API path gotchas: leads, projects/orders, tasks, comments, labels, clients, invoices, vouchers, and forms.
</Note>
