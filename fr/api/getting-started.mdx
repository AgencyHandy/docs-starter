L'API AgencyHandy vous permet d'automatiser la création de leads, la gestion des clients, les mises à jour de commandes et bien plus encore depuis n'importe quel système externe ou script. Chaque requête est authentifiée avec une clé API que vous générez depuis les paramètres de votre espace de travail. Ce guide vous explique comment générer votre clé et effectuer votre premier appel API.

<Note>
  Vous devez être **SuperAdmin** ou **Admin** de votre espace de travail AgencyHandy pour générer une clé API.
</Note>

## URL de base

Toutes les requêtes API sont effectuées vers :

```
https://api.agencyhandy.com/api/v1
```

Remplacez `{{URL}}` par cette URL de base dans tous les exemples de requêtes tout au long de la documentation de l'API.

## Étape 1 : générer une clé API

<Steps>
  <Step title="Ouvrir Workspace Configuration">
    Accédez aux paramètres de votre espace de travail à l'adresse :

    ```
    {{workspaceUrl}}/workspace-config?tab=api-key
    ```

    Cela ouvre l'onglet **API Key** dans Workspace Configuration.
  </Step>

  <Step title="Générer et copier votre clé API">
    Cliquez sur **Generate** (ou **Regenerate** si une clé existe déjà). Copiez la clé API et stockez-la en lieu sûr — traitez-la comme un mot de passe. AgencyHandy ne l'affichera plus après que vous aurez quitté la page.
  </Step>
</Steps>

<Warning>
  Régénérer votre clé API invalide immédiatement la clé précédente. Toute intégration existante utilisant l'ancienne clé cessera de fonctionner jusqu'à ce que vous la mettiez à jour avec la nouvelle clé.
</Warning>

## Étape 2 : Effectuer votre premier appel

Envoyez votre clé API dans l'en-tête `x-api-key`. La clé appartient à un espace de travail : l'API lit donc l'espace de travail à partir de la clé et vous n'avez pas besoin d'envoyer d'ID d'entreprise. Cet appel renvoie l'ID de l'espace de travail de la clé et les espaces de travail qui lui sont liés :

### Point de terminaison

```
GET {{URL}}/accounts/companies
```

### En-têtes

| En-tête | Valeur |
|---|---|
| `x-api-key` | Votre clé API |

### Exemple de requête

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/accounts/companies" \
  --header "x-api-key: <YOUR_API_KEY>"
```

### Exemple de réponse

```json
{
  "message": "Companies accosiated with API token.",
  "companyId": "6525994184e9ddd79853450e",
  "companies": [
    {
      "_id": "6525994184e9ddd79853450e",
      "name": "onethread123",
      "logo": "",
      "extraSmallLogo": "",
      "largeLogo": ""
    }
  ]
}
```

`companyId` est l'espace de travail auquel appartient votre clé API. `companies` répertorie également les espaces de travail parents ou enfants qui y sont liés ; une clé API ne fonctionne que pour son propre espace de travail, créez donc une clé distincte dans chaque espace de travail que vous souhaitez automatiser.

## Récapitulatif de l'authentification

Chaque requête authentifiée n'a besoin que de votre clé API :

```
x-api-key: <YOUR_API_KEY>
```

- **URL de base :** chaque chemin commence par `https://api.agencyhandy.com/api/v1`. Appeler `https://api.agencyhandy.com/accounts/companies` sans `/api/v1` renvoie `404 API not found`.
- **En-tête `companyid` (facultatif) :** d'anciens exemples envoient `companyid: <YOUR_COMPANY_ID>`. Vous pouvez continuer à l'envoyer, mais il doit correspondre à l'ID de l'espace de travail de la clé. Un autre ID est refusé avec `403 PermissionError`.
- **`Authorization: Bearer <YOUR_API_KEY>`** fonctionne aussi si votre outil ne peut envoyer qu'un jeton Bearer. Envoyez la clé dans un seul en-tête, pas dans les deux.
- **`401 Invalid API key (jwt malformed)`** signifie que la valeur n'est pas la clé complète : copiez la clé entière lorsque vous la générez (la liste des clés API n'affiche que ses cinq derniers caractères). **`401 Invalid api token`** signifie que la clé a été supprimée.
- Chaque appel s'exécute avec les autorisations du membre qui a créé la clé.

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/members" \
  --header "x-api-key: <YOUR_API_KEY>"
```

Avec votre clé API, vous êtes prêt à utiliser le reste de l'API AgencyHandy. Passez à l'un des guides de points de terminaison ci-dessous.
