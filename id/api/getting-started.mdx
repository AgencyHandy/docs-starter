API AgencyHandy memungkinkan Anda mengotomatiskan pembuatan lead, manajemen klien, pembaruan pesanan, dan lainnya dari sistem eksternal atau skrip mana pun. Setiap permintaan diautentikasi dengan kunci API yang Anda buat dari pengaturan workspace. Panduan ini memandu Anda membuat kunci dan melakukan panggilan API pertama.

<Note>
  Anda harus menjadi **SuperAdmin** atau **Admin** di workspace AgencyHandy Anda untuk membuat API key.
</Note>

## URL Dasar

Semua permintaan API dibuat ke:

```
https://api.agencyhandy.com/api/v1
```

Ganti `{{URL}}` dengan URL dasar ini di semua contoh permintaan di seluruh dokumentasi API.

## Langkah 1: Buat API key

<Steps>
  <Step title="Buka Workspace Configuration">
    Navigasi ke pengaturan workspace Anda di:

    ```
    {{workspaceUrl}}/workspace-config?tab=api-key
    ```

    Ini membuka tab **API Key** di dalam Workspace Configuration.
  </Step>

  <Step title="Buat dan salin API key Anda">
    Klik **Generate** (atau **Regenerate** jika key sudah ada). Salin API key dan simpan dengan aman — perlakukan seperti kata sandi. AgencyHandy tidak akan menampilkannya lagi setelah Anda meninggalkan halaman.
  </Step>
</Steps>

<Warning>
  Membuat ulang API key Anda segera membatalkan key sebelumnya. Integrasi yang ada menggunakan key lama akan berhenti berfungsi sampai Anda memperbaruinya dengan key baru.
</Warning>

## Langkah 2: Lakukan panggilan pertama Anda

Kirim kunci API Anda di header `x-api-key`. Kunci ini milik satu workspace, sehingga API membaca workspace dari kunci dan Anda tidak perlu mengirim ID perusahaan. Panggilan ini mengembalikan ID workspace milik kunci dan workspace yang terhubung dengannya:

### Endpoint

```
GET {{URL}}/accounts/companies
```

### Header

| Header | Nilai |
|---|---|
| `x-api-key` | API key Anda |

### Contoh permintaan

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/accounts/companies" \
  --header "x-api-key: <YOUR_API_KEY>"
```

### Contoh respons

```json
{
  "message": "Companies accosiated with API token.",
  "companyId": "6525994184e9ddd79853450e",
  "companies": [
    {
      "_id": "6525994184e9ddd79853450e",
      "name": "onethread123",
      "logo": "",
      "extraSmallLogo": "",
      "largeLogo": ""
    }
  ]
}
```

`companyId` adalah workspace tempat kunci API Anda berada. `companies` juga mencantumkan workspace induk atau sub-workspace yang terhubung; kunci API hanya berfungsi untuk workspace-nya sendiri, jadi buat kunci terpisah di setiap workspace yang ingin Anda otomatiskan.

## Ringkasan autentikasi

Setiap permintaan terautentikasi hanya memerlukan kunci API Anda:

```
x-api-key: <YOUR_API_KEY>
```

- **URL dasar:** setiap path diawali dengan `https://api.agencyhandy.com/api/v1`. Memanggil `https://api.agencyhandy.com/accounts/companies` tanpa `/api/v1` mengembalikan `404 API not found`.
- **Header `companyid` (opsional):** contoh lama mengirim `companyid: <YOUR_COMPANY_ID>`. Anda boleh tetap mengirimnya, tetapi harus berupa ID workspace milik kunci tersebut. ID yang berbeda ditolak dengan `403 PermissionError`.
- **`Authorization: Bearer <YOUR_API_KEY>`** juga berfungsi jika alat Anda hanya bisa mengirim token bearer. Kirim kunci hanya di satu header, bukan keduanya.
- **`401 Invalid API key (jwt malformed)`** berarti nilainya bukan kunci lengkap: salin seluruh kunci saat Anda membuatnya (daftar Kunci API hanya menampilkan lima karakter terakhir). **`401 Invalid api token`** berarti kunci telah dihapus.
- Setiap panggilan berjalan dengan izin anggota yang membuat kunci.

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/members" \
  --header "x-api-key: <YOUR_API_KEY>"
```

Dengan kunci API Anda, Anda siap menggunakan bagian lain dari API AgencyHandy. Lanjutkan ke salah satu panduan endpoint di bawah.
