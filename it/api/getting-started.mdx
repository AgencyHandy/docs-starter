L'API di AgencyHandy ti permette di automatizzare la creazione di lead, la gestione dei clienti, gli aggiornamenti degli ordini e altro ancora da qualsiasi sistema esterno o script. Ogni richiesta viene autenticata con una chiave API che generi dalle impostazioni del tuo workspace. Questa guida ti accompagna nella generazione della chiave e nella tua prima chiamata API.

<Note>
  Devi essere **SuperAdmin** o **Admin** nel tuo workspace AgencyHandy per generare una chiave API.
</Note>

## URL di base

Tutte le richieste API vengono effettuate a:

```
https://api.agencyhandy.com/api/v1
```

Sostituisci `{{URL}}` con questo URL di base in tutte le richieste di esempio presenti nella documentazione API.

## Passo 1: Genera una chiave API

<Steps>
  <Step title="Apri la Configurazione del Workspace">
    Naviga alle impostazioni del tuo workspace all'indirizzo:

    ```
    {{workspaceUrl}}/workspace-config?tab=api-key
    ```

    Si apre la scheda **Chiave API** all'interno della Configurazione del Workspace.
  </Step>

  <Step title="Genera e copia la tua chiave API">
    Clicca su **Genera** (o **Rigenera** se esiste già una chiave). Copia la chiave API e conservala in modo sicuro — trattala come una password. AgencyHandy non la mostrerà di nuovo dopo che avrai lasciato la pagina.
  </Step>
</Steps>

<Warning>
  Rigenerare la tua chiave API invalida immediatamente la chiave precedente. Tutte le integrazioni esistenti che utilizzano la vecchia chiave smetteranno di funzionare finché non le aggiorni con la nuova chiave.
</Warning>

## Passaggio 2: Effettua la tua prima chiamata

Invia la tua chiave API nell'header `x-api-key`. La chiave appartiene a un workspace, quindi l'API ricava il workspace dalla chiave e non serve inviare un ID azienda. Questa chiamata restituisce l'ID del workspace della chiave e i workspace collegati:

### Endpoint

```
GET {{URL}}/accounts/companies
```

### Header

| Header | Valore |
|---|---|
| `x-api-key` | La tua chiave API |

### Richiesta di esempio

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/accounts/companies" \
  --header "x-api-key: <YOUR_API_KEY>"
```

### Risposta di esempio

```json
{
  "message": "Companies accosiated with API token.",
  "companyId": "6525994184e9ddd79853450e",
  "companies": [
    {
      "_id": "6525994184e9ddd79853450e",
      "name": "onethread123",
      "logo": "",
      "extraSmallLogo": "",
      "largeLogo": ""
    }
  ]
}
```

`companyId` è il workspace a cui appartiene la tua chiave API. `companies` elenca anche eventuali workspace padre o secondari collegati; una chiave API funziona solo per il proprio workspace, quindi crea una chiave separata in ogni workspace che vuoi automatizzare.

## Riepilogo dell'autenticazione

Ogni richiesta autenticata richiede soltanto la tua chiave API:

```
x-api-key: <YOUR_API_KEY>
```

- **URL di base:** ogni percorso inizia con `https://api.agencyhandy.com/api/v1`. Chiamare `https://api.agencyhandy.com/accounts/companies` senza `/api/v1` restituisce `404 API not found`.
- **Header `companyid` (facoltativo):** i vecchi esempi inviano `companyid: <YOUR_COMPANY_ID>`. Puoi continuare a inviarlo, ma deve essere l'ID del workspace della chiave. Un ID diverso viene rifiutato con `403 PermissionError`.
- **`Authorization: Bearer <YOUR_API_KEY>`** funziona anche se il tuo strumento può inviare solo un token Bearer. Invia la chiave in un solo header, non in entrambi.
- **`401 Invalid API key (jwt malformed)`** significa che il valore non è la chiave completa: copia l'intera chiave quando la generi (l'elenco delle chiavi API mostra solo gli ultimi cinque caratteri). **`401 Invalid api token`** significa che la chiave è stata eliminata.
- Ogni chiamata viene eseguita con i permessi del membro che ha creato la chiave.

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/members" \
  --header "x-api-key: <YOUR_API_KEY>"
```

Con la tua chiave API sei pronto a usare il resto dell'API di AgencyHandy. Continua con una delle guide agli endpoint qui sotto.
