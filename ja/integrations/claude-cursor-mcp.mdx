AgencyHandy の MCP 接続により、**Claude** または **Cursor** に自然言語で話しかけ、AgencyHandy ワークスペースの日常業務を実行できます — すべての画面を自分で開く必要はありません。

操作の主導権はあなたにあります。Claude と Cursor は、あなたが生成したワークスペース API キーでのみ動作し、名前が複数人に一致する場合は確認を求めます。

## 接続方法は 2 つ

| エージェントの動作場所 | 接続方法 | セットアップ |
|---|---|---|
| **自分のパソコン** — Claude Desktop または Cursor | アプリが起動する `agencyhandy-mcp` パッケージ | 下の **Claude または Cursor の MCP を設定する** — Node.js 20+ が必要 |
| **クラウド上** — Cloudflare Workers、Vercel、n8n、ホスト型の Claude や Cursor | `https://mcp.agencyhandy.com/` のホスト型 MCP サーバー | 下の **クラウドエージェントを接続する** — インストール不要 |

どちらも同じワークスペース API キーを使い、エージェントに同じツールを提供します。

<Note>
  **Workspace Config** を開いて **API keys** を管理できるロール（通常は **SuperAdmin** または **Admin**）が必要です。ローカル設定の場合は、Claude Desktop または Cursor を動かすマシンに **Node.js 20+** も必要です。ホスト型サーバーならインストールは一切不要です。
</Note>

## 要件

| 要件 | 詳細 |
|---|---|
| **AgencyHandy ワークスペース** | **Workspace Config** → **API Key** へのアクセス |
| **MCP ホスト** | パソコン上の Claude Desktop や Cursor、または HTTP で MCP サーバーを呼び出せるエージェント |
| **Node.js** *(ローカル設定のみ)* | バージョン **20** 以降（`node -v` で確認） |
| **MCP パッケージ** *(ローカル設定のみ)* | `npx -y agencyhandy-mcp@1`（`1` タグで **1.7.2+** を配信） |

npm 上の MCP パッケージは `agencyhandy-mcp` です。Claude と Cursor は `npx -y agencyhandy-mcp@1` で実行します。

## Claude または Cursor MCP を設定する

Claude Desktop や Cursor を自分のパソコンで動かす場合はこちらです。クラウドで動くエージェントの場合は **クラウドエージェントを接続する** に進んでください。

<Steps>
  <Step title="Workspace Config を開く">
    AgencyHandy で **Workspace Config**（会社設定）を開き、**API Key** タブに進みます。
  </Step>

  <Step title="ワークスペース API キーを生成">
    新しいワークスペース API キーを作成（または保存済みのキーを使用）します。表示されたらコピーしてください — 後から完全なキーを再表示できません。
  </Step>

  <Step title="MCP 設定をコピー">
    同じ **API Key** タブの Claude / Cursor MCP セットアップパネルで **Copy MCP config** をクリックし、キーとバックエンド URL を含む JSON を取得します。
  </Step>

  <Step title="Cursor または Claude Desktop に貼り付け">
    設定を次に貼り付けます：

    - **Cursor**：プロジェクトまたはユーザーの `.mcp.json`
    - **Claude Desktop**：`claude_desktop_config.json`

    生成された `npx -y agencyhandy-mcp@1` コマンドと API キーをそのまま保持します。
  </Step>

  <Step title="再起動してプロンプトを試す">
    **Cursor** または **Claude Desktop** を完全に終了して開き直します。その後、ワークスペースの朝のブリーフィングなど簡単な依頼をしてください。
  </Step>
</Steps>

<Tip>
  Claude または Cursor が MCP サーバーを見つけられない場合は、**Node.js 20+** の導入と、設定保存後のアプリ再起動を確認してください。
</Tip>

## クラウドエージェントを接続する（ホスト型サーバー）

パッケージをインストールできない環境でエージェントを動かしている場合（Cloudflare Workers、Vercel の関数、n8n、ホスト型の Claude や Cursor など）は、当社がホストする MCP サーバーを指定してください:

```
https://mcp.agencyhandy.com/
```

インストールも、維持するサーバーも不要です。同じワークスペース API キーをベアラートークンとして、すべてのリクエストを認証します。ワークスペースはキーから読み取られるため、各ユーザーは自分のキーで接続します。

**Cursor、Claude Code、およびカスタムヘッダーを送信できるホスト:**

```json
{
  "mcpServers": {
    "agency-handy": {
      "url": "https://mcp.agencyhandy.com/",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```

**Claude Desktop** はカスタムヘッダーを送信できないため、`mcp-remote` で中継します:

```json
{
  "mcpServers": {
    "agency-handy": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://mcp.agencyhandy.com/",
        "--header", "Authorization:Bearer YOUR_API_KEY"
      ]
    }
  }
}
```

コマンドラインからの **Claude Code**:

```bash
claude mcp add agency-handy --transport http https://mcp.agencyhandy.com/ \
  --header "Authorization: Bearer YOUR_API_KEY"
```

<Note>
  アドレスは **ルートパス** です — `/mcp` ではなく `https://mcp.agencyhandy.com/`。サーバーに到達できるか確認するには `https://mcp.agencyhandy.com/health` を開いてください。
</Note>

<Tip>
  HTTP API に対して独自の連携を作る場合は、リクエストに **`User-Agent`** ヘッダーを付けてください。Cloudflare Workers の `fetch()` をはじめ、既定では送信しないランタイムがあり、このヘッダーがないリクエストは API に届く前に拒否されます。
</Tip>

## プロンプトの例

自然言語を使います。作業を割り当てるときは、正しい人を選ぶためにフルネームまたはメールを優先してください。

| 目的 | プロンプト例 |
|---|---|
| **朝のブリーフィング** | 「朝のブリーフィングをください：未解決チケット、未払い請求書、クライアント待ちの提案。」 |
| **チケットを割り当て** | 「Acme ホームページ改修のチケットを Jordan Lee（jordan@agency.com）に割り当てて。」 |
| **請求書を送信** | 「請求書 INV-1042 をメールでクライアントに送って。」 |
| **リードを作成** | 「Bright Studio の Nora Patel（nora@brightstudio.com）のリードを作成して。」 |
| **請求書を支払済みにする** | 「請求書 INV-1042 を paid にして。」 |

## 同名の人が二人いる場合

チームに Sara が二人いる場合、Claude はどちらを指すか確認します。ID を**捏造せず**、黙って推測もしません。

名前が衝突しそうなときは、プロンプトに必ず**フルネーム**または**メール**を含めてください。

## クライアントのクレジット、オーダーフォームの閲覧、クライアント会社

**`agencyhandy-mcp@1.17.0`** で提供開始。アプリ内アシスタントの **Handy** もこれらのツールを使います。

| 目的 | ツール | 内容 |
|---|---|---|
| クライアントのクレジット | `ah_client_credits_get` | 残高、保存済みの 1 時間あたりクレジットのレート、残高でまかなえる時間、毎月のクレジット、最近の履歴 |
| クレジットの追加・差し引き | `ah_client_credits_adjust` | クレジットを無料で（購入なしで）追加・差し引き、または **時間** × クライアントの 1 時間あたりクレジットのレートで計算。クライアントはクレジット履歴でメモを確認できます |
| 毎月のクレジット | `ah_client_credit_allowance_set` / `ah_client_credit_allowance_stop` | 指定した毎月の日に、N クレジット**まで補充**（未使用分は積み上がりません）または N クレジットを**追加**（繰り越されます） |
| オーダーフォームを開いた人 | `ah_order_form_views` | オーダーフォームごとの閲覧数、最終閲覧日時、誰も開いていないフォーム（クライアントの訪問のみ） |
| 複数の会社に所属するパートナー | `ah_client_company_add_member` / `ah_client_company_members` | 既存のクライアントをクライアント会社に追加。会社のメンバー、または 1 人のクライアントが所属するすべての会社を一覧表示 |

**プロンプトの例**

- *「1 時間 120 クレジットで、Elizabeth のクレジットからマーケティング作業 2 時間分を差し引いて。」*
- *「毎月 1 日に Acme へ 360 クレジットを付与して。360 まで補充する形で。」*
- *「誰も開いていないオーダーフォームはどれ？」*
- *「パートナーを Apple と Samsung のクライアント会社に追加して。」*

<Note>
  **Handy** では、クレジットの追加・差し引きと毎月のクレジット設定は必ずあなたの承認を待ち、承認できるのは **スーパー管理者** または **管理者** だけです。クレジットの変更はチャットから元に戻せません。代わりに Handy が逆の調整を提案します。
</Note>

## 今できること vs まだできないこと

| 今できること | MCP では未対応 |
|---|---|
| 提案・プロジェクト・チケット・請求書のブリーフィングと検索 | MCP から **client chat** に返信する |
| チケットやその他のチーム作業の割り当て | — |
| リード作成 | — |
| 請求書の送信と支払済み更新 | — |

MCP は API キーでワークスペースの読み取りと操作（作成・割当・送信・更新）をサポートします。クライアントチャットの返信はまだ MCP 経由で公開されていません — その会話は AgencyHandy を使ってください。
