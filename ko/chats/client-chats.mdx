**채팅**은 여러분과 팀이 클라이언트와 실시간으로 메시지를 주고받는 곳입니다. 클라이언트 대화는 한 명의 클라이언트, 즉 기본 클라이언트로 시작합니다. 동료나 관리자 등 클라이언트 측 사람들을 더 추가하여 모두가 같은 스레드에서 함께 소통할 수 있습니다.

왼쪽 사이드바의 **헬프 데스크** 섹션에서 **채팅**을 엽니다.

## 클라이언트 연락처

클라이언트 대화를 열고 **세부 정보** 패널을 엽니다. **클라이언트 연락처** 섹션에는 스레드의 클라이언트 측에 있는 모든 사람이 표시됩니다.

- 기본 클라이언트(**기본**으로 표시됨)
- 추가한 각 연락처와 이메일 주소

![채팅 세부 정보 패널의 클라이언트 연락처 섹션](/images/chats/client-contacts-panel.png)

### 연락처 추가

<Steps>
  <Step title="대화 상자 열기">
    **클라이언트 연락처**에서 **연락처 추가**를 클릭합니다.
  </Step>
  <Step title="추가할 사람 찾기">
    이름이나 이메일로 검색합니다. 목록에는 기본 클라이언트와 같은 회사의 사람들이 먼저 **(회사 이름) 소속** 아래에 표시됩니다. 그다음 워크스페이스의 다른 클라이언트가 **다른 클라이언트** 아래에 표시됩니다. 이미 스레드에 있는 사람은 표시되지 않습니다.
  </Step>
  <Step title="추가하기">
    한 명 이상을 선택하고 **추가**를 클릭합니다.
  </Step>
</Steps>

![클라이언트 회사 사람들이 먼저 표시된 연락처 추가 대화 상자](/images/chats/add-contact-dialog.png)

### 연락처 제거

연락처 옆의 **×** 버튼을 클릭하고 확인합니다. 해당 연락처는 즉시 대화에 접근할 수 없게 됩니다. 기본 클라이언트는 제거할 수 없습니다.

### 제한 사항

- 대화당 최대 20명의 연락처를 추가할 수 있습니다.
- 연락처는 같은 워크스페이스의 기존 클라이언트여야 합니다. 새로운 사람을 추가하려면 먼저 **클라이언트**에서 해당 사람을 클라이언트로 생성하세요.

## 연락처를 관리할 수 있는 사람

| 역할 | 연락처 추가 및 제거 |
|---|---|
| 워크스페이스 관리자 | 가능 |
| 대화에 배정된 팀원 | 가능 |
| 기타 팀원 | 불가 |
| 클라이언트 | 불가 |

## 연락처의 참여 방식

- **이메일 알림.** 모든 연락처가 새 메시지를 이메일로 받습니다.
- **이메일 또는 포털에서 답장.** 연락처는 이메일에 답장하거나 클라이언트 포털에서 채팅을 열 수 있습니다. 이메일 답장은 해당 연락처의 이름으로 같은 대화에 게시됩니다.
- **알 수 없는 발신자는 무시.** 스레드에 없는 이메일 주소에서 보낸 답장은 게시되지 않습니다.
- **읽지 않은 메시지 수 공유.** 스레드의 클라이언트 측에 있는 모든 사람이 하나의 읽지 않은 메시지 수를 공유합니다.

## 개인정보 보호

- 클라이언트는 자신이 참여한 대화만 볼 수 있습니다. 어떤 대화에 추가되더라도 해당 클라이언트의 다른 대화에는 접근할 수 없습니다.
- 클라이언트끼리는 서로의 이메일 주소를 볼 수 없습니다. 포털에서 다른 연락처는 이름과 아바타로만 표시됩니다.

<Tip>
  연락처가 포털에서 보는 화면은 [에이전시와 채팅하기](/ko/client/chat)를 참고하세요.
</Tip>
