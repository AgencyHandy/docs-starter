AgencyHandy MCP savienojums ļauj runāt ar **Claude** vai **Cursor** ikdienas valodā un veikt ikdienas darbu AgencyHandy darba vietā — neatverot katru ekrānu pašam.

Kontrole paliek jums. Claude un Cursor darbojas tikai ar darba vietas API atslēgu, ko ģenerējat, un lūdz apstiprinājumu, ja vārds atbilst vairākām personām.

## Divi savienošanās veidi

| Kur darbojas jūsu aģents | Kā savienot | Iestatīšana |
|---|---|---|
| **Jūsu datorā** — Claude Desktop vai Cursor | Pakotne `agencyhandy-mcp`, ko palaiž lietotne | **Claude vai Cursor MCP iestatīšana** zemāk — nepieciešams Node.js 20+ |
| **Mākonī** — Cloudflare Workers, Vercel, n8n, mitināts Claude vai Cursor | Mūsu mitinātais MCP serveris `https://mcp.agencyhandy.com/` | **Mākoņa aģenta savienošana** zemāk — nekas nav jāinstalē |

Abi izmanto vienu un to pašu darbvietas API atslēgu un dod aģentam tos pašus rīkus.

<Note>
  Nepieciešama loma, kas var atvērt **Workspace Config** un pārvaldīt **API keys** (parasti **SuperAdmin** vai **Admin**). Vietējai iestatīšanai vajadzīgs arī **Node.js 20+** datorā, kurā darbojas Claude Desktop vai Cursor — mitinātajam serverim instalēšana nav vajadzīga vispār.
</Note>

## Prasības

| Prasība | Detaļas |
|---|---|
| **AgencyHandy darbvieta** | Piekļuve **Workspace Config** → **API Key** |
| **MCP resursdators** | Claude Desktop vai Cursor jūsu datorā, vai jebkurš aģents, kas var izsaukt MCP serveri caur HTTP |
| **Node.js** *(tikai vietējai iestatīšanai)* | Versija **20** vai jaunāka (pārbaudiet ar `node -v`) |
| **MCP pakotne** *(tikai vietējai iestatīšanai)* | `npx -y agencyhandy-mcp@1` (birka `1` piegādā **1.7.2+**) |

MCP pakotne npm ir `agencyhandy-mcp`. Claude un Cursor to palaiz ar `npx -y agencyhandy-mcp@1`.

## Claude vai Cursor MCP iestatīšana

Izmantojiet šo ceļu, kad Claude Desktop vai Cursor darbojas jūsu pašu datorā. Ja aģents darbojas mākonī, dodieties uz **Mākoņa aģenta savienošana**.

<Steps>
  <Step title="Atvērt Workspace Config">
    AgencyHandy atveriet **Workspace Config** (uzņēmuma iestatījumi), pēc tam cilni **API Key**.
  </Step>

  <Step title="Ģenerēt darba vietas API atslēgu">
    Izveidojiet jaunu darba vietas API atslēgu (vai izmantojiet saglabāto). Kopējiet atslēgu, kad tā parādās — AgencyHandy vēlāk nevarēs rādīt pilno atslēgu atkārtoti.
  </Step>

  <Step title="Kopēt MCP konfigurāciju">
    Tajā pašā cilnē **API Key** izmantojiet Claude / Cursor MCP paneli. Noklikšķiniet **Copy MCP config**, lai JSON iekļautu atslēgu un backend URL.
  </Step>

  <Step title="Ielīmēt Cursor vai Claude Desktop">
    Ielīmējiet konfigurāciju:

    - **Cursor**: projekta vai lietotāja `.mcp.json`
    - **Claude Desktop**: `claude_desktop_config.json`

    Saglabājiet komandu `npx -y agencyhandy-mcp@1` un API atslēgu kā ģenerēts.
  </Step>

  <Step title="Restartēt un izmēģināt uzvedni">
    Pilnībā aizveriet un atkal atveriet **Cursor** vai **Claude Desktop**. Pēc tam pajautājiet kaut ko vienkāršu, piemēram, rīta briefingu darba vietai.
  </Step>
</Steps>

<Tip>
  Ja Claude vai Cursor neatrod MCP serveri, apstipriniet, ka ir instalēts **Node.js 20+**, un restartējiet lietotni pēc konfigurācijas saglabāšanas.
</Tip>

## Mākoņa aģenta savienošana (mitināts serveris)

Ja jūsu aģents darbojas vietā, kur nevar instalēt pakotni — Cloudflare Workers, Vercel funkcijas, n8n vai mitināts Claude vai Cursor — norādiet to uz MCP serveri, ko uzturam jūsu vietā:

```
https://mcp.agencyhandy.com/
```

Nekas nav jāinstalē un nav jāuztur serveris. Autentificējiet katru pieprasījumu ar to pašu darbvietas API atslēgu kā bearer marķieri. Darbvieta tiek nolasīta no atslēgas, tāpēc katrs lietotājs savienojas ar savu.

**Cursor, Claude Code un jebkurš resursdators, kas sūta pielāgotas galvenes:**

```json
{
  "mcpServers": {
    "agency-handy": {
      "url": "https://mcp.agencyhandy.com/",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```

**Claude Desktop** nevar sūtīt pielāgotas galvenes — izveidojiet tiltu ar `mcp-remote`:

```json
{
  "mcpServers": {
    "agency-handy": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://mcp.agencyhandy.com/",
        "--header", "Authorization:Bearer YOUR_API_KEY"
      ]
    }
  }
}
```

**Claude Code** no komandrindas:

```bash
claude mcp add agency-handy --transport http https://mcp.agencyhandy.com/ \
  --header "Authorization: Bearer YOUR_API_KEY"
```

<Note>
  Adrese ir **saknes ceļš** — `https://mcp.agencyhandy.com/`, nevis `/mcp`. Lai pārbaudītu, vai serveris atbild, atveriet `https://mcp.agencyhandy.com/health`.
</Note>

<Tip>
  Vai tā vietā veidojat savu integrāciju ar HTTP API? Sūtiet pieprasījumiem līdzi **`User-Agent`** galveni. Dažas izpildvides — tostarp Cloudflare Workers `fetch()` — pēc noklusējuma to nesūta, un pieprasījumi bez tās tiek noraidīti, pirms sasniedz API.
</Tip>

## Uzvedņu piemēri

Izmantojiet dabisku valodu. Piešķirot darbu, dodiet priekšroku pilniem vārdiem vai e-pastiem, lai tiktu izvēlēta īstā persona.

| Mērķis | Uzvednes piemērs |
|---|---|
| **Rīta briefing** | “Dod man rīta briefingu: atvērtie ticketi, neapmaksātie rēķini un piedāvājumi, kas gaida klientus.” |
| **Piešķirt ticketu** | “Piešķir Acme sākumlapas redesign ticketu Jordan Lee (jordan@agency.com).” |
| **Nosūtīt rēķinu** | “Nosūti rēķinu INV-1042 klientam pa e-pastu.” |
| **Izveidot lead** | “Izveido lead Nora Patel no Bright Studio, e-pasts nora@brightstudio.com.” |
| **Atzīmēt rēķinu kā apmaksātu** | “Atzīmē rēķinu INV-1042 kā paid.” |

## Kad divām personām ir viens vārds

Ja komandā ir divas Sara, Claude jautās, kuru jūs domājat. Tas **neizdomā** ID un nekļūst klusībā.

Vienmēr iekļaujiet **pilnu vārdu** vai **e-pastu** uzvednē, kad vārdi var sadurties.

## Kas darbojas tagad vs vēl nē

| Darbojas tagad | Vēl nav pieejams no MCP |
|---|---|
| Briefingi un meklēšana piedāvājumiem, projektiem, ticketiem un rēķiniem | Atbildēšana **client chat** no MCP |
| Ticketu un cita komandas darba piešķiršana | — |
| Lead izveide | — |
| Rēķinu sūtīšana un atzīmēšana kā apmaksāti | — |

MCP atbalsta darba vietas lasīšanu un darbības (izveidot, piešķirt, sūtīt, atjaunināt) ar jūsu API atslēgu. Klienta tērzēšanas atbildes vēl nav pieejamas caur MCP — izmantojiet AgencyHandy šīm sarunām.
