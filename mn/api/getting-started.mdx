AgencyHandy API нь лийд үүсгэх, үйлчлүүлэгч удирдах, захиалга шинэчлэх болон бусад үйлдлийг ямар ч гадаад систем эсвэл скриптээс автоматжуулах боломжийг олгоно. Хүсэлт бүр таны ажлын талбарын тохиргооноос үүсгэсэн API түлхүүрээр баталгаажна. Энэ гарын авлага нь түлхүүр үүсгэх болон анхны API дуудлагаа хийхэд тань хөтөлнө.

<Note>
  AgencyHandy воркспейсийнхээ **SuperAdmin** эсвэл **Admin** байж API түлхүүр үүсгэх боломжтой.
</Note>

## Суурь URL

Бүх API хүсэлтийг дараах хаяг руу явуулна:

```
https://api.agencyhandy.com/api/v1
```

API баримт бичгийн бүх жишээ хүсэлтүүдэд `{{URL}}`-г энэ суурь URL-ээр солих хэрэгтэй.

## 1-р алхам: API түлхүүр үүсгэх

<Steps>
  <Step title="Воркспейсийн Тохиргоог нээх">
    Воркспейсийн тохиргоо руу дараах замаар орно уу:

    ```
    {{workspaceUrl}}/workspace-config?tab=api-key
    ```

    Энэ нь Воркспейсийн Тохиргоо доторх **API Key** табыг нээнэ.
  </Step>

  <Step title="API түлхүүрийг үүсгэж хуулах">
    **Generate** (эсвэл түлхүүр аль хэдийн байгаа бол **Regenerate**) дарна уу. API түлхүүрийг хуулж, нууцтай адил найдвартай газар хадгалаарай. Та хуудасыг орхисны дараа AgencyHandy дахин харуулахгүй.
  </Step>
</Steps>

<Warning>
  API түлхүүрийг дахин үүсгэх нь өмнөх түлхүүрийг шууд хүчингүй болгодог. Хуучин түлхүүрийг ашиглаж буй одоогийн интеграцуудыг шинэ түлхүүрээр шинэчлэх хүртэл ажиллахаа болино.
</Warning>

## 2-р алхам: Анхны дуудлагаа хийх

API түлхүүрээ `x-api-key` толгойд илгээнэ. Түлхүүр нэг ажлын талбарт хамаарах тул API ажлын талбарыг түлхүүрээс уншдаг бөгөөд танд компанийн ID илгээх шаардлагагүй. Энэ дуудлага нь түлхүүрийн ажлын талбарын ID болон түүнтэй холбогдсон ажлын талбаруудыг буцаана:

### Эцсийн цэг

```
GET {{URL}}/accounts/companies
```

### Толгойнууд

| Толгой | Утга |
|---|---|
| `x-api-key` | Таны API түлхүүр |

### Жишээ хүсэлт

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/accounts/companies" \
  --header "x-api-key: <YOUR_API_KEY>"
```

### Жишээ хариулт

```json
{
  "message": "Companies accosiated with API token.",
  "companyId": "6525994184e9ddd79853450e",
  "companies": [
    {
      "_id": "6525994184e9ddd79853450e",
      "name": "onethread123",
      "logo": "",
      "extraSmallLogo": "",
      "largeLogo": ""
    }
  ]
}
```

`companyId` нь таны API түлхүүр хамаарах ажлын талбар юм. `companies` нь түүнтэй холбогдсон эцэг эсвэл дэд ажлын талбаруудыг мөн жагсаана; API түлхүүр зөвхөн өөрийн ажлын талбарт ажилладаг тул автоматжуулахыг хүссэн ажлын талбар бүртээ тусдаа түлхүүр үүсгээрэй.

## Баталгаажуулалтын хураангуй

Баталгаажсан хүсэлт бүрт зөвхөн таны API түлхүүр хэрэгтэй:

```
x-api-key: <YOUR_API_KEY>
```

- **Үндсэн URL:** зам бүр `https://api.agencyhandy.com/api/v1`-ээр эхэлнэ. `/api/v1`-гүйгээр `https://api.agencyhandy.com/accounts/companies` руу дуудвал `404 API not found` буцна.
- **`companyid` толгой (заавал биш):** хуучин жишээнүүд `companyid: <YOUR_COMPANY_ID>` илгээдэг. Үүнийг үргэлжлүүлэн илгээж болох ч түлхүүрийн өөрийн ажлын талбарын ID байх ёстой. Өөр ID `403 PermissionError`-оор татгалзагдана.
- Таны хэрэгсэл зөвхөн bearer токен илгээж чаддаг бол **`Authorization: Bearer <YOUR_API_KEY>`** мөн ажиллана. Түлхүүрийг зөвхөн нэг толгойд илгээнэ, хоёуланд нь биш.
- **`401 Invalid API key (jwt malformed)`** нь утга бүтэн түлхүүр биш гэсэн үг: түлхүүрийг үүсгэхдээ бүтнээр нь хуулаарай (API түлхүүрийн жагсаалт зөвхөн сүүлийн таван тэмдэгтийг харуулдаг). **`401 Invalid api token`** нь түлхүүр устгагдсан гэсэн үг.
- Дуудлага бүр түлхүүрийг үүсгэсэн гишүүний эрхээр ажиллана.

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/members" \
  --header "x-api-key: <YOUR_API_KEY>"
```

API түлхүүртэй болсноор та AgencyHandy API-ийн бусад хэсгийг ашиглахад бэлэн боллоо. Доорх эндпойнтын гарын авлагуудын аль нэгээр үргэлжлүүлнэ үү.
