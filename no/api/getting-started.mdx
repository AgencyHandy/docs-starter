AgencyHandy-API-et lar deg automatisere opprettelse av leads, kundehåndtering, ordreoppdateringer og mer fra et hvilket som helst eksternt system eller skript. Hver forespørsel autentiseres med en API-nøkkel som du genererer i innstillingene for arbeidsområdet ditt. Denne guiden viser deg hvordan du genererer nøkkelen og gjør ditt første API-kall.

<Note>
  Du må være **SuperAdmin** eller **Admin** på AgencyHandy-arbeidsområdet ditt for å generere en API-nøkkel.
</Note>

## Basis-URL

Alle API-forespørsler gjøres til:

```
https://api.agencyhandy.com/api/v1
```

Erstatt `{{URL}}` med denne basis-URL-en i alle eksempelforespørsler gjennom API-dokumentasjonen.

## Trinn 1: Generer en API-nøkkel

<Steps>
  <Step title="Åpne Arbeidsområdekonfigurasjon">
    Naviger til arbeidsområdeinnstillingene dine på:

    ```
    {{workspaceUrl}}/workspace-config?tab=api-key
    ```

    Dette åpner **API-nøkkel**-fanen inne i Arbeidsområdekonfigurasjon.
  </Step>

  <Step title="Generer og kopier API-nøkkelen din">
    Klikk **Generer** (eller **Regenerer** hvis en nøkkel allerede eksisterer). Kopier API-nøkkelen og lagre den sikkert — behandle den som et passord. AgencyHandy vil ikke vise den igjen etter at du forlater siden.
  </Step>
</Steps>

<Warning>
  Regenerering av API-nøkkelen din ugyldiggjør umiddelbart den forrige nøkkelen. Alle eksisterende integrasjoner som bruker den gamle nøkkelen vil slutte å fungere til du oppdaterer dem med den nye nøkkelen.
</Warning>

## Trinn 2: Gjør ditt første kall

Send API-nøkkelen din i `x-api-key`-headeren. Nøkkelen tilhører ett arbeidsområde, så API-et leser arbeidsområdet fra nøkkelen, og du trenger ikke sende en bedrifts-ID. Dette kallet returnerer nøkkelens arbeidsområde-ID og arbeidsområdene som er koblet til det:

### Endepunkt

```
GET {{URL}}/accounts/companies
```

### Overskrifter

| Overskrift | Verdi |
|---|---|
| `x-api-key` | API-nøkkelen din |

### Eksempelforespørsel

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/accounts/companies" \
  --header "x-api-key: <YOUR_API_KEY>"
```

### Eksempelsvar

```json
{
  "message": "Companies accosiated with API token.",
  "companyId": "6525994184e9ddd79853450e",
  "companies": [
    {
      "_id": "6525994184e9ddd79853450e",
      "name": "onethread123",
      "logo": "",
      "extraSmallLogo": "",
      "largeLogo": ""
    }
  ]
}
```

`companyId` er arbeidsområdet API-nøkkelen din tilhører. `companies` viser også overordnede eller underordnede arbeidsområder som er koblet til det; en API-nøkkel fungerer bare for sitt eget arbeidsområde, så opprett en egen nøkkel i hvert arbeidsområde du vil automatisere.

## Autentiseringssammendrag

Hver autentiserte forespørsel trenger bare API-nøkkelen din:

```
x-api-key: <YOUR_API_KEY>
```

- **Basis-URL:** hver sti starter med `https://api.agencyhandy.com/api/v1`. Et kall til `https://api.agencyhandy.com/accounts/companies` uten `/api/v1` returnerer `404 API not found`.
- **`companyid`-header (valgfri):** eldre eksempler sender `companyid: <YOUR_COMPANY_ID>`. Du kan fortsette å sende den, men den må være nøkkelens eget arbeidsområde-ID. En annen ID avvises med `403 PermissionError`.
- **`Authorization: Bearer <YOUR_API_KEY>`** fungerer også hvis verktøyet ditt bare kan sende et bearer-token. Send nøkkelen i bare én header, ikke begge.
- **`401 Invalid API key (jwt malformed)`** betyr at verdien ikke er hele nøkkelen: kopier hele nøkkelen når du genererer den (listen over API-nøkler viser bare de fem siste tegnene). **`401 Invalid api token`** betyr at nøkkelen er slettet.
- Hvert kall kjøres med tillatelsene til medlemmet som opprettet nøkkelen.

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/members" \
  --header "x-api-key: <YOUR_API_KEY>"
```

Med API-nøkkelen din er du klar til å bruke resten av AgencyHandy-API-et. Fortsett til en av endepunktguidene nedenfor.
