AgencyHandys MCP-tilkobling lar deg snakke med **Claude** eller **Cursor** på vanlig språk og utføre daglig arbeid i AgencyHandy-arbeidsområdet — uten å åpne hver skjerm selv.

Du beholder kontrollen. Claude og Cursor handler bare med API-nøkkelen for arbeidsområdet du genererer, og ber deg bekrefte når et navn matcher mer enn én person.

## To måter å koble til på

| Hvor agenten din kjører | Slik kobler du til | Oppsett |
|---|---|---|
| **På maskinen din** — Claude Desktop eller Cursor | Pakken `agencyhandy-mcp`, startet av appen | **Sett opp Claude eller Cursor MCP** nedenfor — krever Node.js 20+ |
| **I skyen** — Cloudflare Workers, Vercel, n8n, en hostet Claude eller Cursor | Vår hostede MCP-server på `https://mcp.agencyhandy.com/` | **Koble til en skyagent** nedenfor — ingenting å installere |

Begge bruker den samme API-nøkkelen for arbeidsområdet og gir agenten de samme verktøyene.

<Note>
  Du trenger en rolle som kan åpne **Workspace Config** og administrere **API keys** (vanligvis **SuperAdmin** eller **Admin**). For lokalt oppsett trenger du i tillegg **Node.js 20+** på maskinen der Claude Desktop eller Cursor kjører — den hostede serveren krever ingen installasjon i det hele tatt.
</Note>

## Krav

| Krav | Detaljer |
|---|---|
| **AgencyHandy-arbeidsområde** | Tilgang til **Workspace Config** → **API Key** |
| **En MCP-vert** | Claude Desktop eller Cursor på maskinen din, eller en hvilken som helst agent som kan kalle en MCP-server over HTTP |
| **Node.js** *(kun lokalt oppsett)* | Versjon **20** eller nyere (sjekk med `node -v`) |
| **MCP-pakke** *(kun lokalt oppsett)* | `npx -y agencyhandy-mcp@1` (taggen `1` leverer **1.7.2+**) |

MCP-pakken på npm er `agencyhandy-mcp`. Claude og Cursor kjører den med `npx -y agencyhandy-mcp@1`.

## Sett opp Claude eller Cursor MCP

Bruk denne veien når Claude Desktop eller Cursor kjører på din egen maskin. Kjører agenten i skyen, hopp videre til **Koble til en skyagent**.

<Steps>
  <Step title="Åpne Workspace Config">
    I AgencyHandy, åpne **Workspace Config** (bedriftsinnstillinger) og gå til fanen **API Key**.
  </Step>

  <Step title="Generer en API-nøkkel for arbeidsområdet">
    Opprett en ny API-nøkkel for arbeidsområdet (eller bruk en lagret). Kopier nøkkelen når den vises — AgencyHandy kan ikke vise hele nøkkelen igjen senere.
  </Step>

  <Step title="Kopier MCP-konfigurasjonen">
    På samme fane **API Key**, bruk Claude / Cursor MCP-panelet. Klikk **Copy MCP config** slik at JSON inkluderer nøkkel og backend-URL.
  </Step>

  <Step title="Lim inn i Cursor eller Claude Desktop">
    Lim inn konfigurasjonen i:

    - **Cursor**: prosjekt- eller bruker-`.mcp.json`
    - **Claude Desktop**: `claude_desktop_config.json`

    Behold kommandoen `npx -y agencyhandy-mcp@1` og API-nøkkelen som generert.
  </Step>

  <Step title="Start på nytt og prøv en prompt">
    Avslutt helt og åpne **Cursor** eller **Claude Desktop** på nytt. Be deretter om noe enkelt, for eksempel en morgenbriefing for arbeidsområdet.
  </Step>
</Steps>

<Tip>
  Hvis Claude eller Cursor ikke finner MCP-serveren, bekreft at **Node.js 20+** er installert og at du startet appen på nytt etter lagring av konfigurasjonen.
</Tip>

## Koble til en skyagent (hostet server)

Hvis agenten din kjører et sted du ikke kan installere en pakke — Cloudflare Workers, Vercel-funksjoner, n8n eller en hostet Claude eller Cursor — pek den mot MCP-serveren vi drifter for deg:

```
https://mcp.agencyhandy.com/
```

Det er ingenting å installere og ingen server å holde i gang. Autentiser hver forespørsel med den samme API-nøkkelen for arbeidsområdet som bearer-token. Arbeidsområdet leses fra nøkkelen, så hver bruker kobler seg til med sin egen.

**Cursor, Claude Code og alle verter som sender egne headere:**

```json
{
  "mcpServers": {
    "agency-handy": {
      "url": "https://mcp.agencyhandy.com/",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```

**Claude Desktop** kan ikke sende egne headere — bruk `mcp-remote` som bro:

```json
{
  "mcpServers": {
    "agency-handy": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://mcp.agencyhandy.com/",
        "--header", "Authorization:Bearer YOUR_API_KEY"
      ]
    }
  }
}
```

**Claude Code** fra kommandolinjen:

```bash
claude mcp add agency-handy --transport http https://mcp.agencyhandy.com/ \
  --header "Authorization: Bearer YOUR_API_KEY"
```

<Note>
  Adressen er **rotstien** — `https://mcp.agencyhandy.com/`, ikke `/mcp`. Åpne `https://mcp.agencyhandy.com/health` for å sjekke at serveren svarer.
</Note>

<Tip>
  Bygger du heller din egen integrasjon mot HTTP-API-et? Send med en **`User-Agent`**-header i forespørslene. Enkelte kjøretidsmiljøer — blant annet `fetch()` i Cloudflare Workers — sender ingen som standard, og forespørsler uten blir avvist før de når API-et.
</Tip>

## Eksempelprompter

Bruk naturlig språk. Foretrekk fulle navn eller e-poster når du tildeler arbeid, slik at riktig person velges.

| Mål | Eksempelprompt |
|---|---|
| **Morgenbriefing** | “Gi meg en morgenbriefing: åpne tickets, ubetalte fakturaer og forslag som venter på kunder.” |
| **Tildel en ticket** | “Tildel ticketen om Acme-forsidere design til Jordan Lee (jordan@agency.com).” |
| **Send en faktura** | “Send faktura INV-1042 til kunden på e-post.” |
| **Opprett en lead** | “Opprett en lead for Nora Patel hos Bright Studio, e-post nora@brightstudio.com.” |
| **Merk en faktura som betalt** | “Merk faktura INV-1042 som paid.” |

## Når to personer har samme navn

Hvis to teammedlemmer heter Sara, spør Claude hvem du mener. Den **finner ikke på** ID-er og gjetter ikke i stillhet.

Ta alltid med et **fullt navn** eller en **e-post** i prompten når navn kan kollidere.

## Hva som fungerer nå vs ennå ikke

| Fungerer nå | Ikke tilgjengelig via MCP ennå |
|---|---|
| Briefinger og oppslag på forslag, prosjekter, tickets og fakturaer | Svare i **client chat** via MCP |
| Tildele tickets og annet teamarbeid | — |
| Opprette leads | — |
| Sende fakturaer og merke som betalt | — |

MCP støtter lesing av arbeidsområdet og handlinger (opprette, tildele, sende, oppdatere) med API-nøkkelen. Svar i klientchat er ikke eksponert via MCP ennå — bruk AgencyHandy for de samtalene.

## Relatert

- Generer nøkler og kopier konfigurasjonen i appen under **Workspace Config** → **API Key**
- Hostet server for skyagenter: `https://mcp.agencyhandy.com/` (helsesjekk på `/health`)
- Pakke: [`agencyhandy-mcp`](https://www.npmjs.com/package/agencyhandy-mcp) på npm (`npx -y agencyhandy-mcp@1`)

<Note>
  Latest package on the `1` tag is **1.7.2+**. Claude can read **`ah://api-context`** (also inside **`ah://full-context`**) for API path gotchas: leads, projects/orders, tasks, comments, labels, clients, invoices, vouchers, and forms.
</Note>
