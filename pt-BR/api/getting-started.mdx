A API da AgencyHandy permite automatizar a criação de leads, o gerenciamento de clientes, as atualizações de pedidos e muito mais a partir de qualquer sistema externo ou script. Cada requisição é autenticada com uma chave de API que você gera nas configurações do seu workspace. Este guia explica como gerar sua chave e fazer sua primeira chamada à API.

<Note>
  Você deve ser **SuperAdmin** ou **Admin** no seu workspace do AgencyHandy para gerar uma chave de API.
</Note>

## URL Base

Todas as requisições de API são feitas para:

```
https://api.agencyhandy.com/api/v1
```

Substitua `{{URL}}` por esta URL base em todas as requisições de exemplo ao longo da documentação da API.

## Passo 1: Gerar uma chave de API

<Steps>
  <Step title="Abrir a Configuração do Workspace">
    Navegue até as configurações do seu workspace em:

    ```
    {{workspaceUrl}}/workspace-config?tab=api-key
    ```

    Isso abre a aba **Chave de API** dentro da Configuração do Workspace.
  </Step>

  <Step title="Gerar e copiar sua chave de API">
    Clique em **Gerar** (ou **Regenerar** se já existir uma chave). Copie a chave de API e armazene-a com segurança — trate-a como uma senha. O AgencyHandy não a exibirá novamente após você sair da página.
  </Step>
</Steps>

<Warning>
  Regenerar sua chave de API invalida imediatamente a chave anterior. Quaisquer integrações existentes que usem a chave antiga pararão de funcionar até que você as atualize com a nova chave.
</Warning>

## Passo 2: Faça sua primeira chamada

Envie sua chave de API no cabeçalho `x-api-key`. A chave pertence a um workspace, então a API obtém o workspace a partir da chave e você não precisa enviar um ID de empresa. Esta chamada retorna o ID do workspace da chave e os workspaces vinculados a ele:

### Endpoint

```
GET {{URL}}/accounts/companies
```

### Headers

| Header | Valor |
|---|---|
| `x-api-key` | Sua chave de API |

### Exemplo de requisição

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/accounts/companies" \
  --header "x-api-key: <YOUR_API_KEY>"
```

### Exemplo de resposta

```json
{
  "message": "Companies accosiated with API token.",
  "companyId": "6525994184e9ddd79853450e",
  "companies": [
    {
      "_id": "6525994184e9ddd79853450e",
      "name": "onethread123",
      "logo": "",
      "extraSmallLogo": "",
      "largeLogo": ""
    }
  ]
}
```

`companyId` é o workspace ao qual sua chave de API pertence. `companies` também lista os workspaces pai ou filhos vinculados; uma chave de API só funciona para o próprio workspace, então crie uma chave separada em cada workspace que você quiser automatizar.

## Resumo de autenticação

Cada requisição autenticada precisa apenas da sua chave de API:

```
x-api-key: <YOUR_API_KEY>
```

- **URL base:** todos os caminhos começam com `https://api.agencyhandy.com/api/v1`. Chamar `https://api.agencyhandy.com/accounts/companies` sem `/api/v1` retorna `404 API not found`.
- **Cabeçalho `companyid` (opcional):** exemplos antigos enviam `companyid: <YOUR_COMPANY_ID>`. Você pode continuar enviando, mas ele precisa ser o ID do próprio workspace da chave. Um ID diferente é recusado com `403 PermissionError`.
- **`Authorization: Bearer <YOUR_API_KEY>`** também funciona se sua ferramenta só consegue enviar um token Bearer. Envie a chave em apenas um cabeçalho, não nos dois.
- **`401 Invalid API key (jwt malformed)`** significa que o valor não é a chave completa: copie a chave inteira ao gerá-la (a lista de chaves de API mostra apenas os cinco últimos caracteres). **`401 Invalid api token`** significa que a chave foi excluída.
- Cada chamada é executada com as permissões do membro que criou a chave.

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/members" \
  --header "x-api-key: <YOUR_API_KEY>"
```

Com sua chave de API, você está pronto para usar o restante da API da AgencyHandy. Continue para um dos guias de endpoints abaixo.
