A conexão MCP da AgencyHandy permite falar com o **Claude** ou o **Cursor** em linguagem natural e executar o trabalho diário no seu workspace AgencyHandy — sem abrir cada tela você mesmo.

Você continua no controle. Claude e Cursor só agem com a chave de API do workspace que você gera e pedem confirmação quando um nome corresponde a mais de uma pessoa.

## Duas formas de conectar

| Onde seu agente roda | Como conectar | Configuração |
|---|---|---|
| **No seu computador** — Claude Desktop ou Cursor | O pacote `agencyhandy-mcp`, iniciado pelo aplicativo | **Configurar o MCP do Claude ou Cursor**, abaixo — exige Node.js 20+ |
| **Na nuvem** — Cloudflare Workers, Vercel, n8n, um Claude ou Cursor hospedado | Nosso servidor MCP hospedado em `https://mcp.agencyhandy.com/` | **Conectar um agente na nuvem**, abaixo — nada para instalar |

Os dois usam a mesma chave de API do espaço de trabalho e dão ao agente as mesmas ferramentas.

<Note>
  Você precisa de um papel que possa abrir o **Workspace Config** e gerenciar **API keys** (normalmente **SuperAdmin** ou **Admin**). Para a instalação local você também precisa de **Node.js 20+** na máquina onde o Claude Desktop ou o Cursor roda — o servidor hospedado não exige instalação alguma.
</Note>

## Requisitos

| Requisito | Detalhes |
|---|---|
| **Espaço de trabalho AgencyHandy** | Acesso a **Workspace Config** → **API Key** |
| **Um host MCP** | Claude Desktop ou Cursor no seu computador, ou qualquer agente capaz de chamar um servidor MCP por HTTP |
| **Node.js** *(somente instalação local)* | Versão **20** ou mais recente (`node -v` para conferir) |
| **Pacote MCP** *(somente instalação local)* | `npx -y agencyhandy-mcp@1` (entrega **1.7.2+** na tag `1`) |

O pacote MCP no npm é `agencyhandy-mcp`. Claude e Cursor o executam com `npx -y agencyhandy-mcp@1`.

## Configurar Claude ou Cursor MCP

Use este caminho quando o Claude Desktop ou o Cursor roda no seu próprio computador. Se o agente roda na nuvem, pule para **Conectar um agente na nuvem**.

<Steps>
  <Step title="Abrir Workspace Config">
    No AgencyHandy, abra **Workspace Config** (configurações da empresa) e vá para a aba **API Key**.
  </Step>

  <Step title="Gerar uma chave de API do workspace">
    Crie uma nova chave de API do workspace (ou use uma já salva). Copie a chave quando aparecer — o AgencyHandy não poderá mostrar a chave completa depois.
  </Step>

  <Step title="Copiar a config MCP">
    Na mesma aba **API Key**, use o painel de setup Claude / Cursor MCP. Clique em **Copy MCP config** para que o JSON inclua sua chave e a URL do backend.
  </Step>

  <Step title="Colar no Cursor ou Claude Desktop">
    Cole a config em:

    - **Cursor**: projeto ou usuário `.mcp.json`
    - **Claude Desktop**: `claude_desktop_config.json`

    Mantenha o comando `npx -y agencyhandy-mcp@1` e sua chave de API como gerados.
  </Step>

  <Step title="Reiniciar e testar um prompt">
    Feche completamente e reabra o **Cursor** ou o **Claude Desktop**. Depois peça algo simples, como um briefing matinal do workspace.
  </Step>
</Steps>

<Tip>
  Se Claude ou Cursor não encontrarem o servidor MCP, confirme que o **Node.js 20+** está instalado e que você reiniciou o app após salvar a config.
</Tip>

## Conectar um agente na nuvem (servidor hospedado)

Se seu agente roda onde você não pode instalar um pacote — Cloudflare Workers, funções da Vercel, n8n, ou um Claude ou Cursor hospedado — aponte-o para o servidor MCP que hospedamos para você:

```
https://mcp.agencyhandy.com/
```

Não há nada para instalar nem servidor para manter no ar. Autentique cada requisição com a mesma chave de API do espaço de trabalho como bearer token. O espaço de trabalho é lido da chave, então cada usuário se conecta com a sua.

**Cursor, Claude Code e qualquer host que envie cabeçalhos personalizados:**

```json
{
  "mcpServers": {
    "agency-handy": {
      "url": "https://mcp.agencyhandy.com/",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```

**Claude Desktop** não consegue enviar cabeçalhos personalizados — faça a ponte com `mcp-remote`:

```json
{
  "mcpServers": {
    "agency-handy": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://mcp.agencyhandy.com/",
        "--header", "Authorization:Bearer YOUR_API_KEY"
      ]
    }
  }
}
```

**Claude Code** pela linha de comando:

```bash
claude mcp add agency-handy --transport http https://mcp.agencyhandy.com/ \
  --header "Authorization: Bearer YOUR_API_KEY"
```

<Note>
  O endereço é a **raiz** — `https://mcp.agencyhandy.com/`, não `/mcp`. Para conferir se o servidor responde, abra `https://mcp.agencyhandy.com/health`.
</Note>

<Tip>
  Está construindo sua própria integração com a API HTTP? Envie um cabeçalho **`User-Agent`** nas requisições. Alguns runtimes — incluindo o `fetch()` do Cloudflare Workers — não enviam nenhum por padrão, e requisições sem ele são rejeitadas antes de chegar à API.
</Tip>

## Exemplos de prompts

Use linguagem natural. Prefira nomes completos ou e-mails ao atribuir trabalho para selecionar a pessoa certa.

| Objetivo | Exemplo de prompt |
|---|---|
| **Briefing matinal** | “Me dê um briefing matinal: tickets abertos, faturas não pagas e propostas aguardando clientes.” |
| **Atribuir um ticket** | “Atribua o ticket do redesign da homepage da Acme a Jordan Lee (jordan@agency.com).” |
| **Enviar uma fatura** | “Envie a fatura INV-1042 ao cliente por e-mail.” |
| **Criar um lead** | “Crie um lead para Nora Patel na Bright Studio, e-mail nora@brightstudio.com.” |
| **Marcar uma fatura como paga** | “Marque a fatura INV-1042 como paid.” |

## Quando duas pessoas têm o mesmo nome

Se duas colegas se chamam Sara, o Claude pergunta a qual você se refere. Ele **não inventa** IDs nem adivinha em silêncio.

Inclua sempre um **nome completo** ou **e-mail** no prompt quando os nomes puderem colidir.

## O que funciona agora vs ainda não

| Funciona agora | Ainda não disponível no MCP |
|---|---|
| Briefings e consultas de propostas, projetos, tickets e faturas | Responder no **client chat** pelo MCP |
| Atribuir tickets e outro trabalho da equipe | — |
| Criar leads | — |
| Enviar faturas e marcá-las como pagas | — |

O MCP permite ler seu workspace e executar ações (criar, atribuir, enviar, atualizar) com sua chave de API. Respostas do chat do cliente ainda não estão expostas pelo MCP — use o AgencyHandy para essas conversas.

## Relacionado

- Gere chaves e copie a config no app em **Workspace Config** → **API Key**
- Servidor hospedado para agentes na nuvem: `https://mcp.agencyhandy.com/` (verificação em `/health`)
- Pacote: [`agencyhandy-mcp`](https://www.npmjs.com/package/agencyhandy-mcp) no npm (`npx -y agencyhandy-mcp@1`)

<Note>
  Latest package on the `1` tag is **1.7.2+**. Claude can read **`ah://api-context`** (also inside **`ah://full-context`**) for API path gotchas: leads, projects/orders, tasks, comments, labels, clients, invoices, vouchers, and forms.
</Note>
