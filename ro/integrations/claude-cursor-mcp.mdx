Conexiunea MCP AgencyHandy vă permite să vorbiți cu **Claude** sau **Cursor** în limbaj natural și să rulați munca zilnică în workspace-ul AgencyHandy — fără să deschideți fiecare ecran singuri.

Păstrați controlul. Claude și Cursor acționează doar cu cheia API a workspace-ului pe care o generați și cer confirmare când un nume corespunde mai multor persoane.

## Două moduri de conectare

| Unde rulează agentul tău | Cum îl conectezi | Configurare |
|---|---|---|
| **Pe calculatorul tău** — Claude Desktop sau Cursor | Pachetul `agencyhandy-mcp`, pornit de aplicație | **Configurarea MCP pentru Claude sau Cursor**, mai jos — necesită Node.js 20+ |
| **În cloud** — Cloudflare Workers, Vercel, n8n, un Claude sau Cursor găzduit | Serverul nostru MCP găzduit la `https://mcp.agencyhandy.com/` | **Conectarea unui agent din cloud**, mai jos — nimic de instalat |

Ambele folosesc aceeași cheie API a spațiului de lucru și oferă agentului aceleași instrumente.

<Note>
  Ai nevoie de un rol care poate deschide **Workspace Config** și gestiona **API keys** (de obicei **SuperAdmin** sau **Admin**). Pentru configurarea locală îți mai trebuie **Node.js 20+** pe calculatorul unde rulează Claude Desktop sau Cursor — serverul găzduit nu cere nicio instalare.
</Note>

## Cerințe

| Cerință | Detalii |
|---|---|
| **Spațiu de lucru AgencyHandy** | Acces la **Workspace Config** → **API Key** |
| **O gazdă MCP** | Claude Desktop sau Cursor pe calculatorul tău, ori orice agent care poate apela un server MCP prin HTTP |
| **Node.js** *(doar configurarea locală)* | Versiunea **20** sau mai nouă (verifică `node -v`) |
| **Pachetul MCP** *(doar configurarea locală)* | `npx -y agencyhandy-mcp@1` (eticheta `1` livrează **1.7.2+**) |

Pachetul MCP pe npm este `agencyhandy-mcp`. Claude și Cursor îl rulează cu `npx -y agencyhandy-mcp@1`.

## Configurare Claude sau Cursor MCP

Folosește această cale când Claude Desktop sau Cursor rulează pe calculatorul tău. Dacă agentul rulează în cloud, sari la **Conectarea unui agent din cloud**.

<Steps>
  <Step title="Deschide Workspace Config">
    În AgencyHandy, deschideți **Workspace Config** (setările companiei), apoi fila **API Key**.
  </Step>

  <Step title="Generează o cheie API a workspace-ului">
    Creați o cheie API nouă a workspace-ului (sau folosiți una salvată). Copiați cheia când apare — AgencyHandy nu va putea afișa din nou cheia completă ulterior.
  </Step>

  <Step title="Copiază configurația MCP">
    În aceeași filă **API Key**, folosiți panoul Claude / Cursor MCP. Faceți clic pe **Copy MCP config** ca JSON-ul să includă cheia și URL-ul backend.
  </Step>

  <Step title="Lipește în Cursor sau Claude Desktop">
    Lipiți configurația în:

    - **Cursor**: proiect sau utilizator `.mcp.json`
    - **Claude Desktop**: `claude_desktop_config.json`

    Păstrați comanda `npx -y agencyhandy-mcp@1` și cheia API așa cum au fost generate.
  </Step>

  <Step title="Repornește și încearcă un prompt">
    Închideți complet și redeschideți **Cursor** sau **Claude Desktop**. Apoi cereți ceva simplu, de exemplu un briefing de dimineață pentru workspace.
  </Step>
</Steps>

<Tip>
  Dacă Claude sau Cursor nu găsesc serverul MCP, confirmați că **Node.js 20+** este instalat și că ați repornit aplicația după salvarea configurației.
</Tip>

## Conectarea unui agent din cloud (server găzduit)

Dacă agentul tău rulează undeva unde nu poți instala un pachet — Cloudflare Workers, funcții Vercel, n8n sau un Claude ori Cursor găzduit — îndreaptă-l către serverul MCP pe care îl găzduim pentru tine:

```
https://mcp.agencyhandy.com/
```

Nu ai nimic de instalat și niciun server de întreținut. Autentifică fiecare cerere cu aceeași cheie API a spațiului de lucru, ca bearer token. Spațiul de lucru se citește din cheie, așa că fiecare utilizator se conectează cu a lui.

**Cursor, Claude Code și orice gazdă care trimite anteturi personalizate:**

```json
{
  "mcpServers": {
    "agency-handy": {
      "url": "https://mcp.agencyhandy.com/",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```

**Claude Desktop** nu poate trimite anteturi personalizate — fă puntea cu `mcp-remote`:

```json
{
  "mcpServers": {
    "agency-handy": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://mcp.agencyhandy.com/",
        "--header", "Authorization:Bearer YOUR_API_KEY"
      ]
    }
  }
}
```

**Claude Code** din linia de comandă:

```bash
claude mcp add agency-handy --transport http https://mcp.agencyhandy.com/ \
  --header "Authorization: Bearer YOUR_API_KEY"
```

<Note>
  Adresa este **calea rădăcină** — `https://mcp.agencyhandy.com/`, nu `/mcp`. Ca să verifici că serverul răspunde, deschide `https://mcp.agencyhandy.com/health`.
</Note>

<Tip>
  Îți construiești în schimb propria integrare peste API-ul HTTP? Trimite un antet **`User-Agent`** cu cererile tale. Unele medii de execuție — inclusiv `fetch()` din Cloudflare Workers — nu trimit niciunul implicit, iar cererile fără el sunt respinse înainte să ajungă la API.
</Tip>

## Exemple de prompturi

Folosiți limbaj natural. Preferă nume complete sau e-mailuri când atribuiți muncă, ca să fie selectată persoana potrivită.

| Obiectiv | Exemplu de prompt |
|---|---|
| **Briefing de dimineață** | “Dă-mi un briefing de dimineață: ticket-uri deschise, facturi neplătite și propuneri care așteaptă clienții.” |
| **Atribuie un ticket** | “Atribuie ticket-ul despre redesign-ul homepage Acme către Jordan Lee (jordan@agency.com).” |
| **Trimite o factură** | “Trimite factura INV-1042 clientului pe e-mail.” |
| **Creează un lead** | “Creează un lead pentru Nora Patel de la Bright Studio, e-mail nora@brightstudio.com.” |
| **Marchează o factură ca plătită** | “Marchează factura INV-1042 ca paid.” |

## Când două persoane au același nume

Dacă două colege se numesc Sara, Claude întreabă pe care o intenționați. **Nu inventează** ID-uri și nu ghicește în tăcere.

Includeți întotdeauna un **nume complet** sau un **e-mail** în prompt când numele se pot ciocni.

## Ce funcționează acum vs încă nu

| Funcționează acum | Încă indisponibil din MCP |
|---|---|
| Briefinguri și căutări pentru propuneri, proiecte, ticket-uri și facturi | Răspuns în **client chat** din MCP |
| Atribuirea ticket-urilor și a altei munci de echipă | — |
| Crearea de lead-uri | — |
| Trimiterea facturilor și marcarea ca plătite | — |

MCP permite citirea workspace-ului și acțiuni (creare, atribuire, trimitere, actualizare) cu cheia API. Răspunsurile din chat-ul client nu sunt încă expuse prin MCP — folosiți AgencyHandy pentru acele conversații.

## Conexe

- Generați chei și copiați configurația în aplicație la **Workspace Config** → **API Key**

<Note>
  Latest package on the `1` tag is **1.7.2+**. Claude can read **`ah://api-context`** (also inside **`ah://full-context`**) for API path gotchas: leads, projects/orders, tasks, comments, labels, clients, invoices, vouchers, and forms.
</Note>

- Server găzduit pentru agenți din cloud: `https://mcp.agencyhandy.com/` (verificare la `/health`)
- Pachet: [`agencyhandy-mcp`](https://www.npmjs.com/package/agencyhandy-mcp) pe npm (`npx -y agencyhandy-mcp@1`)
