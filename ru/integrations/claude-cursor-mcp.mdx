MCP-подключение AgencyHandy позволяет говорить с **Claude** или **Cursor** обычным языком и выполнять повседневную работу в рабочем пространстве AgencyHandy — без открытия каждого экрана вручную.

Контроль остаётся за вами. Claude и Cursor действуют только с API-ключом пространства, который вы создаёте, и просят подтверждение, если имя совпадает с несколькими людьми.

## Два способа подключения

| Где работает ваш агент | Как подключить | Настройка |
|---|---|---|
| **На вашем компьютере** — Claude Desktop или Cursor | Пакет `agencyhandy-mcp`, который запускает приложение | **Настройка MCP для Claude или Cursor** ниже — нужен Node.js 20+ |
| **В облаке** — Cloudflare Workers, Vercel, n8n, размещённый Claude или Cursor | Наш размещённый MCP-сервер по адресу `https://mcp.agencyhandy.com/` | **Подключение облачного агента** ниже — ничего устанавливать не нужно |

Оба способа используют один и тот же API-ключ рабочего пространства и дают агенту одинаковые инструменты.

<Note>
  Нужна роль, которая может открывать **Workspace Config** и управлять **API keys** (обычно **SuperAdmin** или **Admin**). Для локальной установки также нужен **Node.js 20+** на компьютере, где работает Claude Desktop или Cursor — размещённому серверу установка не требуется вовсе.
</Note>

## Требования

| Требование | Подробности |
|---|---|
| **Рабочее пространство AgencyHandy** | Доступ к **Workspace Config** → **API Key** |
| **MCP-хост** | Claude Desktop или Cursor на компьютере либо любой агент, способный вызвать MCP-сервер по HTTP |
| **Node.js** *(только локальная установка)* | Версия **20** или новее (проверьте `node -v`) |
| **MCP-пакет** *(только локальная установка)* | `npx -y agencyhandy-mcp@1` (тег `1` содержит **1.7.2+**) |

MCP-пакет на npm — `agencyhandy-mcp`. Claude и Cursor запускают его командой `npx -y agencyhandy-mcp@1`.

## Настройка Claude или Cursor MCP

Используйте этот способ, когда Claude Desktop или Cursor работает на вашем компьютере. Если агент работает в облаке, переходите к разделу **Подключение облачного агента**.

<Steps>
  <Step title="Открыть Workspace Config">
    В AgencyHandy откройте **Workspace Config** (настройки компании), затем вкладку **API Key**.
  </Step>

  <Step title="Создать API-ключ пространства">
    Создайте новый API-ключ пространства (или используйте сохранённый). Скопируйте ключ, когда он появится — позже AgencyHandy не сможет показать полный ключ снова.
  </Step>

  <Step title="Скопировать MCP-конфиг">
    На той же вкладке **API Key** используйте панель настройки Claude / Cursor MCP. Нажмите **Copy MCP config**, чтобы JSON включил ключ и URL бэкенда.
  </Step>

  <Step title="Вставить в Cursor или Claude Desktop">
    Вставьте конфиг в:

    - **Cursor**: проектный или пользовательский `.mcp.json`
    - **Claude Desktop**: `claude_desktop_config.json`

    Сохраните команду `npx -y agencyhandy-mcp@1` и API-ключ как сгенерировано.
  </Step>

  <Step title="Перезапустить и проверить запрос">
    Полностью закройте и снова откройте **Cursor** или **Claude Desktop**. Затем попросите что-то простое, например утренний брифинг по пространству.
  </Step>
</Steps>

<Tip>
  Если Claude или Cursor не находят MCP-сервер, убедитесь, что установлен **Node.js 20+**, и перезапустите приложение после сохранения конфига.
</Tip>

## Подключение облачного агента (размещённый сервер)

Если агент работает там, где нельзя установить пакет — Cloudflare Workers, функции Vercel, n8n или размещённый Claude либо Cursor — направьте его на MCP-сервер, который мы держим для вас:

```
https://mcp.agencyhandy.com/
```

Ничего не нужно устанавливать и не нужно поддерживать сервер. Аутентифицируйте каждый запрос тем же API-ключом рабочего пространства как bearer-токеном. Рабочее пространство читается из ключа, поэтому каждый пользователь подключается со своим.

**Cursor, Claude Code и любой хост, который отправляет собственные заголовки:**

```json
{
  "mcpServers": {
    "agency-handy": {
      "url": "https://mcp.agencyhandy.com/",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```

**Claude Desktop** не умеет отправлять собственные заголовки — используйте мост `mcp-remote`:

```json
{
  "mcpServers": {
    "agency-handy": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://mcp.agencyhandy.com/",
        "--header", "Authorization:Bearer YOUR_API_KEY"
      ]
    }
  }
}
```

**Claude Code** из командной строки:

```bash
claude mcp add agency-handy --transport http https://mcp.agencyhandy.com/ \
  --header "Authorization: Bearer YOUR_API_KEY"
```

<Note>
  Адрес — это **корневой путь**: `https://mcp.agencyhandy.com/`, а не `/mcp`. Чтобы проверить доступность сервера, откройте `https://mcp.agencyhandy.com/health`.
</Note>

<Tip>
  Строите собственную интеграцию с HTTP API? Отправляйте заголовок **`User-Agent`** вместе с запросами. Некоторые среды выполнения — включая `fetch()` в Cloudflare Workers — по умолчанию его не отправляют, и запросы без него отклоняются, не доходя до API.
</Tip>

## Примеры запросов

Используйте естественный язык. При назначении работы предпочитайте полные имена или email, чтобы выбрать нужного человека.

| Цель | Пример запроса |
|---|---|
| **Утренний брифинг** | «Дай утренний брифинг: открытые тикеты, неоплаченные счета и предложения в ожидании клиентов.» |
| **Назначить тикет** | «Назначь тикет по редизайну главной Acme на Jordan Lee (jordan@agency.com).» |
| **Отправить счёт** | «Отправь счёт INV-1042 клиенту по email.» |
| **Создать лид** | «Создай лид для Nora Patel из Bright Studio, email nora@brightstudio.com.» |
| **Отметить счёт оплаченным** | «Отметь счёт INV-1042 как paid.» |

## Когда у двух людей одно имя

Если в команде две Сары, Claude спросит, кого вы имеете в виду. Он **не придумывает** ID и не угадывает молча.

Всегда указывайте **полное имя** или **email** в запросе, если имена могут совпасть.

## Что работает сейчас vs ещё нет

| Работает сейчас | Пока недоступно через MCP |
|---|---|
| Брифинги и поиск по предложениям, проектам, тикетам и счетам | Ответы в **client chat** через MCP |
| Назначение тикетов и другой командной работы | — |
| Создание лидов | — |
| Отправка счетов и отметка об оплате | — |

MCP позволяет читать пространство и выполнять действия (создать, назначить, отправить, обновить) с вашим API-ключом. Ответы в клиентском чате через MCP пока не доступны — используйте AgencyHandy для этих разговоров.

## Связанные материалы

- Создавайте ключи и копируйте конфиг в приложении: **Workspace Config** → **API Key**

<Note>
  Latest package on the `1` tag is **1.7.2+**. Claude can read **`ah://api-context`** (also inside **`ah://full-context`**) for API path gotchas: leads, projects/orders, tasks, comments, labels, clients, invoices, vouchers, and forms.
</Note>

- Размещённый сервер для облачных агентов: `https://mcp.agencyhandy.com/` (проверка через `/health`)
- Пакет: [`agencyhandy-mcp`](https://www.npmjs.com/package/agencyhandy-mcp) на npm (`npx -y agencyhandy-mcp@1`)
