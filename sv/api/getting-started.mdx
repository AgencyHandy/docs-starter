AgencyHandy-API:et låter dig automatisera skapande av leads, kundhantering, orderuppdateringar och mer från valfritt externt system eller skript. Varje begäran autentiseras med en API-nyckel som du skapar i din arbetsytas inställningar. Den här guiden går igenom hur du skapar din nyckel och gör ditt första API-anrop.

<Note>
  Du måste vara **SuperAdmin** eller **Admin** på din AgencyHandy-arbetsyta för att generera en API-nyckel.
</Note>

## Bas-URL

Alla API-begäranden görs till:

```
https://api.agencyhandy.com/api/v1
```

Ersätt `{{URL}}` med denna bas-URL i alla exempelbegäranden i API-dokumentationen.

## Steg 1: Generera en API-nyckel

<Steps>
  <Step title="Öppna arbetsytekonfiguration">
    Navigera till dina arbetsyteinställningar på:

    ```
    {{workspaceUrl}}/workspace-config?tab=api-key
    ```

    Detta öppnar fliken **API-nyckel** i Arbetsytekonfiguration.
  </Step>

  <Step title="Generera och kopiera din API-nyckel">
    Klicka på **Generera** (eller **Regenerera** om en nyckel redan finns). Kopiera API-nyckeln och förvara den säkert — behandla den som ett lösenord. AgencyHandy visar den inte igen efter att du lämnat sidan.
  </Step>
</Steps>

<Warning>
  Om du regenererar din API-nyckel ogiltigförklaras den tidigare nyckeln omedelbart. Alla befintliga integrationer som använder den gamla nyckeln slutar fungera tills du uppdaterar dem med den nya nyckeln.
</Warning>

## Steg 2: Gör ditt första anrop

Skicka din API-nyckel i `x-api-key`-huvudet. Nyckeln tillhör en arbetsyta, så API:et läser arbetsytan från nyckeln och du behöver inte skicka något företags-ID. Det här anropet returnerar nyckelns arbetsyte-ID och de arbetsytor som är kopplade till den:

### Endpoint

```
GET {{URL}}/accounts/companies
```

### Huvuden

| Huvud | Värde |
|---|---|
| `x-api-key` | Din API-nyckel |

### Exempelbegäran

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/accounts/companies" \
  --header "x-api-key: <YOUR_API_KEY>"
```

### Exempelsvar

```json
{
  "message": "Companies accosiated with API token.",
  "companyId": "6525994184e9ddd79853450e",
  "companies": [
    {
      "_id": "6525994184e9ddd79853450e",
      "name": "onethread123",
      "logo": "",
      "extraSmallLogo": "",
      "largeLogo": ""
    }
  ]
}
```

`companyId` är den arbetsyta som din API-nyckel tillhör. `companies` listar även överordnade eller underordnade arbetsytor som är kopplade till den; en API-nyckel fungerar bara för sin egen arbetsyta, så skapa en separat nyckel i varje arbetsyta du vill automatisera.

## Sammanfattning av autentisering

Varje autentiserad begäran behöver bara din API-nyckel:

```
x-api-key: <YOUR_API_KEY>
```

- **Bas-URL:** varje sökväg börjar med `https://api.agencyhandy.com/api/v1`. Ett anrop till `https://api.agencyhandy.com/accounts/companies` utan `/api/v1` returnerar `404 API not found`.
- **`companyid`-huvud (valfritt):** äldre exempel skickar `companyid: <YOUR_COMPANY_ID>`. Du kan fortsätta skicka det, men det måste vara nyckelns egna arbetsyte-ID. Ett annat ID avvisas med `403 PermissionError`.
- **`Authorization: Bearer <YOUR_API_KEY>`** fungerar också om ditt verktyg bara kan skicka en bearer-token. Skicka nyckeln i endast ett huvud, inte båda.
- **`401 Invalid API key (jwt malformed)`** betyder att värdet inte är hela nyckeln: kopiera hela nyckeln när du skapar den (API-nyckellistan visar bara de fem sista tecknen). **`401 Invalid api token`** betyder att nyckeln har raderats.
- Varje anrop körs med behörigheterna för den medlem som skapade nyckeln.

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/members" \
  --header "x-api-key: <YOUR_API_KEY>"
```

Med din API-nyckel är du redo att använda resten av AgencyHandy-API:et. Fortsätt till en av endpoint-guiderna nedan.
