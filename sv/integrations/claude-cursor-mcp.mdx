AgencyHandys MCP-anslutning låter dig prata med **Claude** eller **Cursor** på vardagsspråk och utföra vardagsarbete i din AgencyHandy-arbetsyta — utan att öppna varje skärm själv.

Du behåller kontrollen. Claude och Cursor agerar bara med det API-nyckel för arbetsytan som du skapar, och ber dig bekräfta när ett namn matchar mer än en person.

## Två sätt att ansluta

| Var din agent körs | Så ansluter du | Uppsättning |
|---|---|---|
| **På din dator** — Claude Desktop eller Cursor | Paketet `agencyhandy-mcp`, som appen startar | **Ställ in Claude eller Cursor MCP** nedan — kräver Node.js 20+ |
| **I molnet** — Cloudflare Workers, Vercel, n8n, en hostad Claude eller Cursor | Vår hostade MCP-server på `https://mcp.agencyhandy.com/` | **Anslut en molnagent** nedan — inget att installera |

Båda använder samma API-nyckel för arbetsytan och ger agenten samma verktyg.

<Note>
  Du behöver en roll som kan öppna **Workspace Config** och hantera **API keys** (vanligtvis **SuperAdmin** eller **Admin**). För den lokala uppsättningen behöver du dessutom **Node.js 20+** på datorn där Claude Desktop eller Cursor körs — den hostade servern kräver ingen installation alls.
</Note>

## Krav

| Krav | Detaljer |
|---|---|
| **AgencyHandy-arbetsyta** | Åtkomst till **Workspace Config** → **API Key** |
| **En MCP-värd** | Claude Desktop eller Cursor på din dator, eller vilken agent som helst som kan anropa en MCP-server över HTTP |
| **Node.js** *(endast lokal uppsättning)* | Version **20** eller senare (kontrollera med `node -v`) |
| **MCP-paket** *(endast lokal uppsättning)* | `npx -y agencyhandy-mcp@1` (taggen `1` levererar **1.7.2+**) |

MCP-paketet på npm är `agencyhandy-mcp`. Claude och Cursor kör det med `npx -y agencyhandy-mcp@1`.

## Konfigurera Claude eller Cursor MCP

Använd det här när Claude Desktop eller Cursor körs på din egen dator. Körs agenten i molnet, hoppa vidare till **Anslut en molnagent**.

<Steps>
  <Step title="Öppna Workspace Config">
    I AgencyHandy, öppna **Workspace Config** (företagsinställningar) och gå till fliken **API Key**.
  </Step>

  <Step title="Generera en API-nyckel för arbetsytan">
    Skapa en ny API-nyckel för arbetsytan (eller använd en sparad). Kopiera nyckeln när den visas — AgencyHandy kan inte visa hela nyckeln igen senare.
  </Step>

  <Step title="Kopiera MCP-konfigurationen">
    På samma flik **API Key**, använd Claude / Cursor MCP-panelen. Klicka på **Copy MCP config** så att JSON inkluderar nyckel och backend-URL.
  </Step>

  <Step title="Klistra in i Cursor eller Claude Desktop">
    Klistra in konfigurationen i:

    - **Cursor**: projekt- eller användar-`.mcp.json`
    - **Claude Desktop**: `claude_desktop_config.json`

    Behåll kommandot `npx -y agencyhandy-mcp@1` och din API-nyckel som genererats.
  </Step>

  <Step title="Starta om och testa en prompt">
    Avsluta helt och öppna **Cursor** eller **Claude Desktop** igen. Be sedan om något enkelt, till exempel en morgonbriefing för arbetsytan.
  </Step>
</Steps>

<Tip>
  Om Claude eller Cursor inte hittar MCP-servern, bekräfta att **Node.js 20+** är installerat och att du startat om appen efter att ha sparat konfigurationen.
</Tip>

## Anslut en molnagent (hostad server)

Om din agent körs där du inte kan installera ett paket — Cloudflare Workers, Vercel-funktioner, n8n, eller en hostad Claude eller Cursor — peka den mot MCP-servern som vi driver åt dig:

```
https://mcp.agencyhandy.com/
```

Det finns inget att installera och ingen server att hålla igång. Autentisera varje anrop med samma API-nyckel för arbetsytan som bearer-token. Arbetsytan läses från nyckeln, så varje användare ansluter med sin egen.

**Cursor, Claude Code och alla värdar som skickar egna headers:**

```json
{
  "mcpServers": {
    "agency-handy": {
      "url": "https://mcp.agencyhandy.com/",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```

**Claude Desktop** kan inte skicka egna headers — brygga med `mcp-remote`:

```json
{
  "mcpServers": {
    "agency-handy": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://mcp.agencyhandy.com/",
        "--header", "Authorization:Bearer YOUR_API_KEY"
      ]
    }
  }
}
```

**Claude Code** från kommandoraden:

```bash
claude mcp add agency-handy --transport http https://mcp.agencyhandy.com/ \
  --header "Authorization: Bearer YOUR_API_KEY"
```

<Note>
  Adressen är **rotsökvägen** — `https://mcp.agencyhandy.com/`, inte `/mcp`. Öppna `https://mcp.agencyhandy.com/health` för att kontrollera att servern svarar.
</Note>

<Tip>
  Bygger du i stället en egen integration mot HTTP-API:et? Skicka med en **`User-Agent`**-header i dina anrop. Vissa körmiljöer — bland andra `fetch()` i Cloudflare Workers — skickar ingen som standard, och anrop utan header avvisas innan de når API:et.
</Tip>

## Exempelpromptar

Använd naturligt språk. Föredra fullständiga namn eller e-post när du tilldelar arbete så att rätt person väljs.

| Mål | Exempelprompt |
|---|---|
| **Morgonbriefing** | “Ge mig en morgonbriefing: öppna tickets, obetalda fakturor och förslag som väntar på kunder.” |
| **Tilldela en ticket** | “Tilldela ticketen om Acme-hemsidans redesign till Jordan Lee (jordan@agency.com).” |
| **Skicka en faktura** | “Skicka faktura INV-1042 till kunden via e-post.” |
| **Skapa en lead** | “Skapa en lead för Nora Patel på Bright Studio, e-post nora@brightstudio.com.” |
| **Markera en faktura som betald** | “Markera faktura INV-1042 som paid.” |

## När två personer delar samma namn

Om två teammedlemmar heter Sara frågar Claude vilken du menar. Den **hittar inte på** ID:n och gissar inte tyst.

Inkludera alltid ett **fullständigt namn** eller en **e-postadress** i prompten när namn kan krocka.

## Vad som fungerar nu vs ännu inte

| Fungerar nu | Inte tillgängligt via MCP ännu |
|---|---|
| Briefingar och sökningar i förslag, projekt, tickets och fakturor | Svara i **client chat** via MCP |
| Tilldela tickets och annat teamarbete | — |
| Skapa leads | — |
| Skicka fakturor och markera som betalda | — |

MCP stöder läsning av arbetsytan och åtgärder (skapa, tilldela, skicka, uppdatera) med din API-nyckel. Svar i klientchatten är ännu inte tillgängliga via MCP — använd AgencyHandy för de samtalen.
