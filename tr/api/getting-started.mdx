AgencyHandy API'si, potansiyel müşteri oluşturma, müşteri yönetimi, sipariş güncellemeleri ve daha fazlasını herhangi bir harici sistemden veya betikten otomatikleştirmenizi sağlar. Her istek, çalışma alanı ayarlarınızdan oluşturduğunuz bir API anahtarıyla doğrulanır. Bu kılavuz, anahtarınızı oluşturmanızda ve ilk API çağrınızı yapmanızda size yol gösterir.

<Note>
  API anahtarı oluşturabilmek için AgencyHandy çalışma alanınızda **SuperAdmin** veya **Admin** olmanız gerekir.
</Note>

## Temel URL

Tüm API istekleri şu adrese yapılır:

```
https://api.agencyhandy.com/api/v1
```

API belgelerindeki tüm örnek isteklerde `{{URL}}` ifadesini bu temel URL ile değiştirin.

## 1. Adım: API anahtarı oluşturun

<Steps>
  <Step title="Çalışma Alanı Yapılandırması'nı açın">
    Çalışma alanı ayarlarınıza şu adresten gidin:

    ```
    {{workspaceUrl}}/workspace-config?tab=api-key
    ```

    Bu, Çalışma Alanı Yapılandırması içindeki **API Anahtarı** sekmesini açar.
  </Step>

  <Step title="API anahtarınızı oluşturun ve kopyalayın">
    **Oluştur** (veya zaten bir anahtar mevcutsa **Yeniden Oluştur**) düğmesine tıklayın. API anahtarını kopyalayın ve güvenli bir yerde saklayın — bir parola gibi davranın. AgencyHandy sayfadan ayrıldıktan sonra anahtarı tekrar göstermez.
  </Step>
</Steps>

<Warning>
  API anahtarını yeniden oluşturmak, önceki anahtarı hemen geçersiz kılar. Eski anahtarı kullanan mevcut entegrasyonlar, yeni anahtarla güncellenene kadar çalışmayı durduracaktır.
</Warning>

## Adım 2: İlk çağrınızı yapın

API anahtarınızı `x-api-key` başlığında gönderin. Anahtar tek bir çalışma alanına aittir; bu nedenle API çalışma alanını anahtardan okur ve bir Şirket Kimliği göndermeniz gerekmez. Bu çağrı, anahtarın çalışma alanı kimliğini ve ona bağlı çalışma alanlarını döndürür:

### Uç nokta

```
GET {{URL}}/accounts/companies
```

### Başlıklar

| Başlık | Değer |
|---|---|
| `x-api-key` | API anahtarınız |

### Örnek istek

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/accounts/companies" \
  --header "x-api-key: <YOUR_API_KEY>"
```

### Örnek yanıt

```json
{
  "message": "Companies accosiated with API token.",
  "companyId": "6525994184e9ddd79853450e",
  "companies": [
    {
      "_id": "6525994184e9ddd79853450e",
      "name": "onethread123",
      "logo": "",
      "extraSmallLogo": "",
      "largeLogo": ""
    }
  ]
}
```

`companyId`, API anahtarınızın ait olduğu çalışma alanıdır. `companies` ayrıca ona bağlı üst veya alt çalışma alanlarını da listeler; bir API anahtarı yalnızca kendi çalışma alanı için geçerlidir, bu yüzden otomatikleştirmek istediğiniz her çalışma alanında ayrı bir anahtar oluşturun.

## Kimlik doğrulama özeti

Kimliği doğrulanmış her istek yalnızca API anahtarınızı gerektirir:

```
x-api-key: <YOUR_API_KEY>
```

- **Temel URL:** her yol `https://api.agencyhandy.com/api/v1` ile başlar. `https://api.agencyhandy.com/accounts/companies` adresini `/api/v1` olmadan çağırmak `404 API not found` döndürür.
- **`companyid` başlığı (isteğe bağlı):** eski örnekler `companyid: <YOUR_COMPANY_ID>` gönderir. Göndermeye devam edebilirsiniz, ancak anahtarın kendi çalışma alanı kimliği olmalıdır. Farklı bir kimlik `403 PermissionError` ile reddedilir.
- Aracınız yalnızca bearer belirteci gönderebiliyorsa **`Authorization: Bearer <YOUR_API_KEY>`** da çalışır. Anahtarı yalnızca tek bir başlıkta gönderin, ikisinde birden değil.
- **`401 Invalid API key (jwt malformed)`**, değerin anahtarın tamamı olmadığı anlamına gelir: anahtarı oluştururken tamamını kopyalayın (API Anahtarı listesi yalnızca son beş karakteri gösterir). **`401 Invalid api token`**, anahtarın silindiği anlamına gelir.
- Her çağrı, anahtarı oluşturan üyenin izinleriyle çalışır.

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/members" \
  --header "x-api-key: <YOUR_API_KEY>"
```

API anahtarınızla AgencyHandy API'sinin geri kalanını kullanmaya hazırsınız. Aşağıdaki uç nokta kılavuzlarından birine devam edin.
