AgencyHandy’nin MCP bağlantısı, **Claude** veya **Cursor** ile doğal dilde konuşup AgencyHandy çalışma alanındaki günlük işleri çalıştırmanızı sağlar — her ekranı kendiniz açmadan.

Kontrol sizde kalır. Claude ve Cursor yalnızca oluşturduğunuz çalışma alanı API anahtarıyla hareket eder ve bir ad birden fazla kişiyle eşleşirse onay ister.

## Bağlanmanın iki yolu

| Aracınız nerede çalışıyor | Nasıl bağlanır | Kurulum |
|---|---|---|
| **Bilgisayarınızda** — Claude Desktop veya Cursor | Uygulamanın başlattığı `agencyhandy-mcp` paketi | Aşağıdaki **Claude veya Cursor MCP kurulumu** — Node.js 20+ gerekir |
| **Bulutta** — Cloudflare Workers, Vercel, n8n, barındırılan Claude veya Cursor | `https://mcp.agencyhandy.com/` adresindeki barındırılan MCP sunucumuz | Aşağıdaki **Bulut aracısı bağlama** — kurulum gerekmez |

İkisi de aynı çalışma alanı API anahtarını kullanır ve aracıya aynı araçları verir.

<Note>
  **Workspace Config** ekranını açabilen ve **API keys** yönetebilen bir role ihtiyacınız var (genellikle **SuperAdmin** veya **Admin**). Yerel kurulum için ayrıca Claude Desktop ya da Cursor'ın çalıştığı makinede **Node.js 20+** gerekir — barındırılan sunucu hiçbir kurulum istemez.
</Note>

## Gereksinimler

| Gereksinim | Ayrıntılar |
|---|---|
| **AgencyHandy çalışma alanı** | **Workspace Config** → **API Key** erişimi |
| **Bir MCP ana uygulaması** | Bilgisayarınızdaki Claude Desktop veya Cursor ya da bir MCP sunucusunu HTTP üzerinden çağırabilen herhangi bir aracı |
| **Node.js** *(yalnızca yerel kurulum)* | Sürüm **20** veya üzeri (`node -v` ile kontrol edin) |
| **MCP paketi** *(yalnızca yerel kurulum)* | `npx -y agencyhandy-mcp@1` (`1` etiketi **1.7.2+** sürümünü verir) |

npm’deki MCP paketi `agencyhandy-mcp`’dir. Claude ve Cursor bunu `npx -y agencyhandy-mcp@1` ile çalıştırır.

## Claude veya Cursor MCP’yi kurun

Claude Desktop veya Cursor kendi bilgisayarınızda çalışıyorsa bu yolu izleyin. Aracınız bulutta çalışıyorsa **Bulut aracısı bağlama** bölümüne geçin.

<Steps>
  <Step title="Workspace Config’i açın">
    AgencyHandy’de **Workspace Config**’i (şirket ayarları) açın, ardından **API Key** sekmesine gidin.
  </Step>

  <Step title="Çalışma alanı API anahtarı oluşturun">
    Yeni bir çalışma alanı API anahtarı oluşturun (veya kaydettiğiniz birini kullanın). Göründüğünde kopyalayın — AgencyHandy daha sonra tam anahtarı tekrar gösteremez.
  </Step>

  <Step title="MCP yapılandırmasını kopyalayın">
    Aynı **API Key** sekmesinde Claude / Cursor MCP kurulum panelini kullanın. JSON’un anahtarınızı ve backend URL’sini içermesi için **Copy MCP config**’e tıklayın.
  </Step>

  <Step title="Cursor veya Claude Desktop’a yapıştırın">
    Yapılandırmayı şuraya yapıştırın:

    - **Cursor**: proje veya kullanıcı `.mcp.json`
    - **Claude Desktop**: `claude_desktop_config.json`

    `npx -y agencyhandy-mcp@1` komutunu ve API anahtarını üretildiği gibi bırakın.
  </Step>

  <Step title="Yeniden başlatın ve bir istem deneyin">
    **Cursor** veya **Claude Desktop**’ı tamamen kapatıp yeniden açın. Ardından çalışma alanı için sabah brifingi gibi basit bir şey isteyin.
  </Step>
</Steps>

<Tip>
  Claude veya Cursor MCP sunucusunu bulamazsa **Node.js 20+** kurulu olduğunu ve yapılandırmayı kaydettikten sonra uygulamayı yeniden başlattığınızı doğrulayın.
</Tip>

## Bulut aracısı bağlama (barındırılan sunucu)

Aracınız paket kuramayacağınız bir yerde çalışıyorsa — Cloudflare Workers, Vercel fonksiyonları, n8n veya barındırılan Claude ya da Cursor — onu sizin için işlettiğimiz MCP sunucusuna yönlendirin:

```
https://mcp.agencyhandy.com/
```

Kurulacak bir şey ve ayakta tutulacak bir sunucu yok. Her isteği aynı çalışma alanı API anahtarıyla bearer token olarak doğrulayın. Çalışma alanı anahtardan okunur, böylece her kullanıcı kendi anahtarıyla bağlanır.

**Cursor, Claude Code ve özel başlık gönderebilen tüm ana uygulamalar:**

```json
{
  "mcpServers": {
    "agency-handy": {
      "url": "https://mcp.agencyhandy.com/",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```

**Claude Desktop** özel başlık gönderemez; `mcp-remote` ile köprü kurun:

```json
{
  "mcpServers": {
    "agency-handy": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://mcp.agencyhandy.com/",
        "--header", "Authorization:Bearer YOUR_API_KEY"
      ]
    }
  }
}
```

Komut satırından **Claude Code**:

```bash
claude mcp add agency-handy --transport http https://mcp.agencyhandy.com/ \
  --header "Authorization: Bearer YOUR_API_KEY"
```

<Note>
  Adres **kök yoldur** — `/mcp` değil, `https://mcp.agencyhandy.com/`. Sunucunun erişilebilir olduğunu görmek için `https://mcp.agencyhandy.com/health` adresini açın.
</Note>

<Tip>
  Bunun yerine HTTP API üzerine kendi entegrasyonunuzu mu kuruyorsunuz? İsteklerinizle birlikte bir **`User-Agent`** başlığı gönderin. Cloudflare Workers'ın `fetch()` işlevi dahil bazı çalışma ortamları varsayılan olarak hiç göndermez ve bu başlık olmayan istekler API'ye ulaşmadan reddedilir.
</Tip>

## Örnek istemler

Doğal dil kullanın. İş atarken doğru kişiyi seçmek için tam ad veya e-postayı tercih edin.

| Hedef | Örnek istem |
|---|---|
| **Sabah brifingi** | “Bana bir sabah brifingi ver: açık ticket’lar, ödenmemiş faturalar ve müşteri bekleyen teklifler.” |
| **Ticket ata** | “Acme ana sayfa yenileme ticket’ını Jordan Lee’ye (jordan@agency.com) ata.” |
| **Fatura gönder** | “INV-1042 faturasını e-posta ile müşteriye gönder.” |
| **Lead oluştur** | “Bright Studio’dan Nora Patel için lead oluştur, e-posta nora@brightstudio.com.” |
| **Faturayı ödendi işaretle** | “INV-1042 faturasını paid olarak işaretle.” |

## İki kişi aynı adı paylaştığında

Ekipte iki Sara varsa Claude hangisini kastettiğinizi sorar. ID **uydurmaz** ve sessizce tahmin etmez.

Adlar çakışabileceğinde istemde her zaman **tam ad** veya **e-posta** ekleyin.

## Şimdi çalışan vs henüz değil

| Şimdi çalışıyor | MCP’den henüz yok |
|---|---|
| Teklif, proje, ticket ve faturalarda brifing ve arama | MCP’den **client chat** yanıtı |
| Ticket ve diğer ekip işlerini atama | — |
| Lead oluşturma | — |
| Fatura gönderme ve ödendi işaretleme | — |

MCP, API anahtarınızla çalışma alanını okumayı ve eylemleri (oluştur, ata, gönder, güncelle) destekler. Müşteri sohbet yanıtları henüz MCP üzerinden açık değil — bu konuşmalar için AgencyHandy’yi kullanın.
