AgencyHandy API lidlar yaratish, mijozlarni boshqarish, buyurtmalarni yangilash va boshqa ishlarni istalgan tashqi tizim yoki skriptdan avtomatlashtirish imkonini beradi. Har bir so'rov workspace sozlamalaringizdan yaratgan API kaliti bilan autentifikatsiya qilinadi. Ushbu qo'llanma kalitni yaratish va birinchi API chaqiruvini bajarishda yordam beradi.

<Note>
  API kalitini yaratish uchun AgencyHandy ish muhitida **SuperAdmin** yoki **Admin** bo'lishingiz shart.
</Note>

## Asosiy URL

Barcha API so'rovlari quyidagi manzilga yuboriladi:

```
https://api.agencyhandy.com/api/v1
```

API hujjatlaridagi barcha namuna so'rovlarda `{{URL}}` ni ushbu asosiy URL bilan almashtiring.

## 1-qadam: API kalitini yarating

<Steps>
  <Step title="Ish muhiti konfiguratsiyasini oching">
    Quyidagi manzil orqali ish muhiti sozlamalariga o'ting:

    ```
    {{workspaceUrl}}/workspace-config?tab=api-key
    ```

    Bu Workspace Configuration ichidagi **API Key** tabini ochadi.
  </Step>

  <Step title="API kalitini yarating va nusxalang">
    **Generate** (yoki kalit allaqachon mavjud bo'lsa **Regenerate**) tugmasini bosing. API kalitini nusxalang va uni xavfsiz joyda saqlang — uni parol kabi muomala qiling. AgencyHandy sahifadan chiqib ketganingizdan so'ng uni yana ko'rsatmaydi.
  </Step>
</Steps>

<Warning>
  API kalitini qayta yaratish oldingi kalitni darhol bekor qiladi. Eski kalitdan foydalanadigan mavjud integratsiyalar yangi kalit bilan yangilanmaguncha ishlashni to'xtatadi.
</Warning>

## 2-qadam: Birinchi chaqiruvingizni bajaring

API kalitingizni `x-api-key` sarlavhasida yuboring. Kalit bitta workspace'ga tegishli, shuning uchun API workspace'ni kalitdan o'qiydi va kompaniya ID'sini yuborishingiz shart emas. Bu chaqiruv kalitning workspace ID'sini va unga bog'langan workspace'larni qaytaradi:

### Endpoint

```
GET {{URL}}/accounts/companies
```

### Sarlavhalar

| Sarlavha | Qiymat |
|---|---|
| `x-api-key` | Sizning API kalitingiz |

### Namuna so'rov

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/accounts/companies" \
  --header "x-api-key: <YOUR_API_KEY>"
```

### Namuna javob

```json
{
  "message": "Companies accosiated with API token.",
  "companyId": "6525994184e9ddd79853450e",
  "companies": [
    {
      "_id": "6525994184e9ddd79853450e",
      "name": "onethread123",
      "logo": "",
      "extraSmallLogo": "",
      "largeLogo": ""
    }
  ]
}
```

`companyId` — API kalitingiz tegishli bo'lgan workspace. `companies` shuningdek unga bog'langan asosiy yoki quyi workspace'larni ham ko'rsatadi; API kaliti faqat o'z workspace'i uchun ishlaydi, shuning uchun avtomatlashtirmoqchi bo'lgan har bir workspace'da alohida kalit yarating.

## Autentifikatsiya xulosasi

Har bir autentifikatsiyalangan so'rov uchun faqat API kalitingiz kerak:

```
x-api-key: <YOUR_API_KEY>
```

- **Asosiy URL:** har bir yo'l `https://api.agencyhandy.com/api/v1` bilan boshlanadi. `https://api.agencyhandy.com/accounts/companies` manzilini `/api/v1`siz chaqirsangiz, `404 API not found` qaytadi.
- **`companyid` sarlavhasi (ixtiyoriy):** eski misollar `companyid: <YOUR_COMPANY_ID>` yuboradi. Uni yuborishda davom etishingiz mumkin, lekin u kalitning o'z workspace ID'si bo'lishi kerak. Boshqa ID `403 PermissionError` bilan rad etiladi.
- Agar vositangiz faqat bearer tokenini yubora olsa, **`Authorization: Bearer <YOUR_API_KEY>`** ham ishlaydi. Kalitni faqat bitta sarlavhada yuboring, ikkalasida emas.
- **`401 Invalid API key (jwt malformed)`** qiymat to'liq kalit emasligini bildiradi: kalitni yaratganingizda uni to'liq nusxalang (API kalitlar ro'yxati faqat oxirgi besh belgini ko'rsatadi). **`401 Invalid api token`** kalit o'chirilganini bildiradi.
- Har bir chaqiruv kalitni yaratgan a'zoning ruxsatlari bilan bajariladi.

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/members" \
  --header "x-api-key: <YOUR_API_KEY>"
```

API kalitingiz bilan AgencyHandy API'sining qolgan qismidan foydalanishga tayyorsiz. Quyidagi endpoint qo'llanmalaridan biriga o'ting.
