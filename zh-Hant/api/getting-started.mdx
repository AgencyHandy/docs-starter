AgencyHandy API 讓您可以從任何外部系統或指令碼自動化建立潛在客戶、管理客戶、更新訂單等操作。每個請求都使用您在工作區設定中產生的 API 金鑰進行驗證。本指南將引導您產生金鑰並發出第一次 API 呼叫。

<Note>
  您必須是 AgencyHandy 工作區的 **SuperAdmin** 或 **Admin** 才能產生 API 金鑰。
</Note>

## 基礎 URL

所有 API 請求均向以下地址發送：

```
https://api.agencyhandy.com/api/v1
```

在 API 文件中所有範例請求中，請以此基礎 URL 替換 `{{URL}}`。

## 步驟 1：產生 API 金鑰

<Steps>
  <Step title="開啟工作區設定">
    前往您的工作區設定：

    ```
    {{workspaceUrl}}/workspace-config?tab=api-key
    ```

    這將開啟工作區設定中的 **API Key** 標籤頁。
  </Step>

  <Step title="產生並複製您的 API 金鑰">
    點擊 **Generate**（若金鑰已存在則點擊 **Regenerate**）。複製 API 金鑰並妥善儲存 — 請將其視為密碼。離開頁面後，AgencyHandy 將不再顯示此金鑰。
  </Step>
</Steps>

<Warning>
  重新產生 API 金鑰會立即使舊金鑰失效。任何使用舊金鑰的現有整合將停止運作，直到您使用新金鑰更新它們為止。
</Warning>

## 步驟 2：發出第一次呼叫

在 `x-api-key` 標頭中傳送您的 API 金鑰。金鑰屬於一個工作區，因此 API 會從金鑰讀取工作區，您不需要傳送公司 ID。此呼叫會傳回該金鑰的工作區 ID 以及與之連結的工作區：

### 端點

```
GET {{URL}}/accounts/companies
```

### 標頭

| 標頭 | 值 |
|---|---|
| `x-api-key` | 您的 API 金鑰 |

### 範例請求

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/accounts/companies" \
  --header "x-api-key: <YOUR_API_KEY>"
```

### 範例回應

```json
{
  "message": "Companies accosiated with API token.",
  "companyId": "6525994184e9ddd79853450e",
  "companies": [
    {
      "_id": "6525994184e9ddd79853450e",
      "name": "onethread123",
      "logo": "",
      "extraSmallLogo": "",
      "largeLogo": ""
    }
  ]
}
```

`companyId` 是您的 API 金鑰所屬的工作區。`companies` 也會列出與之連結的任何上層或子工作區；API 金鑰僅適用於其自身的工作區，因此請在每個要自動化的工作區中分別建立金鑰。

## 驗證摘要

每個經過驗證的請求只需要您的 API 金鑰：

```
x-api-key: <YOUR_API_KEY>
```

- **基礎 URL：** 每個路徑都以 `https://api.agencyhandy.com/api/v1` 開頭。未帶 `/api/v1` 就呼叫 `https://api.agencyhandy.com/accounts/companies` 會傳回 `404 API not found`。
- **`companyid` 標頭（選用）：** 較早的範例會傳送 `companyid: <YOUR_COMPANY_ID>`。您可以繼續傳送，但它必須是該金鑰自身的工作區 ID。不同的 ID 會被拒絕並傳回 `403 PermissionError`。
- 如果您的工具只能傳送 Bearer 權杖，**`Authorization: Bearer <YOUR_API_KEY>`** 同樣有效。只在一個標頭中傳送金鑰，不要同時在兩個標頭中傳送。
- **`401 Invalid API key (jwt malformed)`** 表示該值不是完整的金鑰：產生時請複製整個金鑰（API 金鑰清單只顯示最後五個字元）。**`401 Invalid api token`** 表示該金鑰已被刪除。
- 每次呼叫都以建立該金鑰的成員的權限執行。

```bash cURL
curl --request GET "https://api.agencyhandy.com/api/v1/members" \
  --header "x-api-key: <YOUR_API_KEY>"
```

有了 API 金鑰，您就可以使用 AgencyHandy API 的其餘功能了。請繼續閱讀下面的任一端點指南。
