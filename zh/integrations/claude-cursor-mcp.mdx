AgencyHandy 的 MCP 连接让你用自然语言与 **Claude** 或 **Cursor** 对话，并在 AgencyHandy 工作区中执行日常工作——无需自己打开每一个界面。

控制权始终在你。Claude 和 Cursor 只会使用你生成的工作区 API 密钥操作，并在姓名匹配多人时请你确认。

## 两种连接方式

| 智能体运行位置 | 连接方式 | 设置 |
|---|---|---|
| **在你的电脑上** — Claude Desktop 或 Cursor | 由应用启动的 `agencyhandy-mcp` 包 | 见下方 **设置 Claude 或 Cursor MCP** — 需要 Node.js 20+ |
| **在云端** — Cloudflare Workers、Vercel、n8n、托管的 Claude 或 Cursor | 我们托管的 MCP 服务器 `https://mcp.agencyhandy.com/` | 见下方 **连接云端智能体** — 无需安装 |

两种方式使用同一个工作区 API 密钥，并为智能体提供相同的工具。

<Note>
  你需要能够打开 **Workspace Config** 并管理 **API keys** 的角色（通常是 **SuperAdmin** 或 **Admin**）。本地方式还需要在运行 Claude Desktop 或 Cursor 的电脑上安装 **Node.js 20+**；托管服务器则完全无需安装。
</Note>

## 要求

| 要求 | 详情 |
|---|---|
| **AgencyHandy 工作区** | 可访问 **Workspace Config** → **API Key** |
| **一个 MCP 宿主** | 电脑上的 Claude Desktop 或 Cursor，或任何能通过 HTTP 调用 MCP 服务器的智能体 |
| **Node.js** *(仅本地方式)* | 版本 **20** 或更高（用 `node -v` 查看） |
| **MCP 包** *(仅本地方式)* | `npx -y agencyhandy-mcp@1`（`1` 标签提供 **1.7.2+**） |

npm 上的 MCP 包名为 `agencyhandy-mcp`。Claude 和 Cursor 通过 `npx -y agencyhandy-mcp@1` 运行它。

## 设置 Claude 或 Cursor MCP

当 Claude Desktop 或 Cursor 运行在你自己的电脑上时使用这种方式。如果智能体运行在云端，请直接跳到 **连接云端智能体**。

<Steps>
  <Step title="打开 Workspace Config">
    在 AgencyHandy 中打开 **Workspace Config**（公司设置），然后进入 **API Key** 选项卡。
  </Step>

  <Step title="生成工作区 API 密钥">
    创建新的工作区 API 密钥（或使用已保存的密钥）。出现时请立即复制——之后 AgencyHandy 无法再次显示完整密钥。
  </Step>

  <Step title="复制 MCP 配置">
    在同一 **API Key** 选项卡中，使用 Claude / Cursor MCP 设置面板。点击 **Copy MCP config**，使 JSON 包含你的密钥和后端 URL。
  </Step>

  <Step title="粘贴到 Cursor 或 Claude Desktop">
    将配置粘贴到：

    - **Cursor**：项目或用户 `.mcp.json`
    - **Claude Desktop**：`claude_desktop_config.json`

    保留生成的 `npx -y agencyhandy-mcp@1` 命令和 API 密钥。
  </Step>

  <Step title="重启并尝试提示">
    完全退出并重新打开 **Cursor** 或 **Claude Desktop**。然后提出一个简单请求，例如工作区晨报。
  </Step>
</Steps>

<Tip>
  如果 Claude 或 Cursor 找不到 MCP 服务器，请确认已安装 **Node.js 20+**，并在保存配置后重启应用。
</Tip>

## 连接云端智能体（托管服务器）

如果你的智能体运行在无法安装软件包的环境中——Cloudflare Workers、Vercel 函数、n8n，或托管的 Claude、Cursor——请把它指向我们为你托管的 MCP 服务器：

```
https://mcp.agencyhandy.com/
```

无需安装，也不用维护服务器。用同一个工作区 API 密钥作为 bearer token 认证每个请求。工作区从密钥中读取，因此每位用户使用自己的密钥连接。

**Cursor、Claude Code 以及任何可发送自定义请求头的宿主：**

```json
{
  "mcpServers": {
    "agency-handy": {
      "url": "https://mcp.agencyhandy.com/",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```

**Claude Desktop** 无法发送自定义请求头，请用 `mcp-remote` 中转：

```json
{
  "mcpServers": {
    "agency-handy": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://mcp.agencyhandy.com/",
        "--header", "Authorization:Bearer YOUR_API_KEY"
      ]
    }
  }
}
```

命令行中的 **Claude Code**：

```bash
claude mcp add agency-handy --transport http https://mcp.agencyhandy.com/ \
  --header "Authorization: Bearer YOUR_API_KEY"
```

<Note>
  地址是**根路径** —— `https://mcp.agencyhandy.com/`，而不是 `/mcp`。要确认服务器可达，请打开 `https://mcp.agencyhandy.com/health`。
</Note>

<Tip>
  如果你改为基于 HTTP API 自建集成，请在请求中发送 **`User-Agent`** 头。包括 Cloudflare Workers 的 `fetch()` 在内的一些运行时默认不发送该头，缺少它的请求会在到达 API 之前被拒绝。
</Tip>

## 示例提示

使用自然语言。分配工作时请尽量使用全名或邮箱，以便选中正确的人。

| 目标 | 示例提示 |
|---|---|
| **晨报** | “给我一份晨报：未结工单、未付发票，以及等待客户的提案。” |
| **分配工单** | “把 Acme 首页改版相关工单分配给 Jordan Lee（jordan@agency.com）。” |
| **发送发票** | “通过邮件把发票 INV-1042 发送给客户。” |
| **创建线索** | “为 Bright Studio 的 Nora Patel 创建线索，邮箱 nora@brightstudio.com。” |
| **标记发票已付** | “将发票 INV-1042 标记为 paid。” |

## 当两个人同名时

如果两名同事都叫 Sara，Claude 会询问你指的是哪一位。它**不会编造** ID，也不会默默猜测。

当姓名可能冲突时，请始终在提示中包含**全名**或**邮箱**。

## 当前可用 vs 尚不可用

| 当前可用 | MCP 尚不支持 |
|---|---|
| 提案、项目、工单和发票的晨报与查询 | 通过 MCP 在 **client chat** 中回复 |
| 分配工单及其他团队工作 | — |
| 创建线索 | — |
| 发送发票并标记为已付 | — |

MCP 支持使用你的 API 密钥读取工作区并执行操作（创建、分配、发送、更新）。客户端聊天回复尚未通过 MCP 开放——请在 AgencyHandy 中处理这些对话。
